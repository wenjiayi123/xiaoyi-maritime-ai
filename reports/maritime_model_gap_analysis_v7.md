# 小懿AI 港航模型 v7 基线差距、改进与复测

生成日期：2026-07-27

## 评测方法

- 检索：参考 BEIR 的跨域信息检索评测思想，记录 Recall@5、MRR@10 和
  nDCG@10。参考：<https://arxiv.org/abs/2104.08663>。
- RAG 回答：按 RAGAS 的 Context Precision、Context Recall、Response
  Relevancy 和 Faithfulness 概念建立确定性任务代理，并另做引用、主张和
  数字完整性校验。参考：
  <https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/>。
- 本地延迟：按 MLPerf 风格记录 TTFT、TPOT、总耗时和生成吞吐。参考：
  <https://mlcommons.org/benchmarks/client/>。

这些结果是仓库维护的单机、单流、固定工程基准，不是 BEIR、RAGAS 或
MLPerf 官方提交，也不是港航专家盲评、生产 SLA 或职业健康验证。

## 改进前基线

基线报告：`reports/maritime_model_benchmark_v7_baseline.json`

- 35 题通过 16 题，通过率 45.71%。
- 检索 Recall@5 为 1.0000、MRR@10 为 0.9778、nDCG@10 为 0.9833，
  说明主要问题不在“检索不到”，而在生成层对已检索答案的删改。
- 26 道带必需控制点的题，必需术语召回为 0.6731。
- TTFT P50/P95 为 7.9791/9.1858 秒，总耗时 P50/P95 为
  13.5751/17.0642 秒。

## 发现的主要不足

1. 生成层省略关键港航控制点：船舶准时到港漏“船长”，闸口拥堵漏“场内
   拥堵”，滚装漏“系固”，VGM 漏“箱号”，铁路延误漏“替代运力/冷链”，
   结构异常漏“工程人员”，火情漏“复工”。
2. 商务与管理闭环表达不足：费用争议漏“费率版本/不得承诺减免”，货损漏
   “责任”，多部门协同漏“唯一阻断项”，箱量预测漏“上下界/正式计划”。
3. AI 建议边界表达不完整：漏“生产授权”，法规具体限值题可能被基座补写
   一般知识，形成幻觉风险。
4. 生活化问题错误进入港航知识检索，出现主题错配；正常生活回应、作业影响和
   分岗位建议没有稳定分层。
5. 大部分问题重复经过生成基座，已存在的完整证据答案仍需等待 7–9 秒首字。

## 实施的改进

- 增加 18 条基线差距监督和 12 条港航人员日常监督；v3 数据集共 841 条，
  按来源隔离为 622/94/125，并在构建前排除 212 道固定评测问题。
- 在 17.29 亿参数同架构训练基座上完成 Rank 96、Alpha 192、64 step
  LoRA，实际训练 104,595,456 个适配器参数；含适配器总参数
  1,825,170,432，训练参数占 5.730723%。
- 8 条验证样本损失从 4.880868 降到 2.755390，8 条测试样本从
  5.356009 降到 3.187271；该结果只作为固定隔离样本的优化信号。
- 对完整、可引用且与证据原文一致的港航答案启用快速路径；实时数据、官方全文
  和业务对象缺失时直接返回核验边界，不让基座补写具体事实。
- 对常见疲劳、健康、情绪、通勤、高温、咖啡、运动、饮酒和饮食问题采用
  “正常回答 → 港航作业影响 → 船员/引航/中控/调度/装卸/闸口/维修建议”
  结构，未命中证据时在底部提示。
- 前端新增持续滚动的解析、检索、核证、路由和组织回答状态；所有回答统一使用
  稳定打字机渲染并节流滚动，减少等待误判与窗口闪动。
- 所有回答路径从请求开始后统一保留至少 3 秒可见核验窗口，期间滚动展示意图
  解析、检索、来源/边界核对和答案组织状态，再开始逐字输出；若模型自身首字时间
  已超过 3 秒则不再叠加等待。该窗口用于提供一致的操作反馈，不被解释为单靠
  延迟即可提高准确率。

## 最终复测

最终报告：`reports/maritime_model_benchmark_v7_lora_r96.json`

- 港航业务 30/30、澄清/实时/法规边界 5/5、港航人员日常题 16/16，
  合计 51/51。
- Recall@5、MRR@10、nDCG@10 均为 1.0000；26 道必需控制点题术语召回
  为 1.0000，引用校验通过率和确定性 faithfulness 代理均为 1.0000。
- 所有路径启用最短 3 秒可见核验窗口后，整体 TTFT P50/P95 为
  3.0075/3.0125 秒，总耗时 P50/P95 为 3.0335/3.0406 秒；30 道索引
  命中题 TTFT P50/P95 为 3.0067/3.0128 秒，5 道边界题为
  3.0110/3.0113 秒，16 道港航人员日常题为 3.0088/3.0118 秒。
- 适配器裸推理探针实测约 11.4 token/s；Rank 96 会增加提示词计算开销，
  因此速度收益来自路由、证据直出、上下文压缩和前端流式体验，而不是把参数
  规模增加误写为推理加速。
