# IMO 国际安全管理规则（ISM Code）

## 来源定位

- 发布机构：International Maritime Organization（IMO）
- 官方页面：https://www.imo.org/en/ourwork/humanelement/pages/ismcode.aspx
- 规则来源：Resolution A.741(18)，通过 SOLAS 第 IX 章成为强制要求
- 核验日期：2026-07-12
- 资料性质：IMO 官方页面的目的、适用逻辑和修订入口摘要；不替代 ISM Code、SOLAS、船公司安全管理体系或港口现场制度。

## 已核验事实

- ISM Code 的目的是为船舶安全管理与操作以及污染预防提供国际标准。
- 规则采用一般原则与目标，要求公司评估对船舶、人员和环境已识别的风险并建立适当防护措施。
- 有效安全管理依赖组织各层级的承诺、能力、态度和动机；不同岸基与船上岗位需要与职责相匹配的知识和意识。
- IMO 官方页面列出与 ISM 相关的实施、指定人员、险情报告、网络风险管理等指导文件入口。

## 船岸协同问答

### 船方和码头对一项风险判断不一致，谁先执行？

先停止可能扩大风险的动作并明确当前控制边界。船方负责船舶安全管理和船上操作，码头负责其设施、人员和港区作业控制；双方应通过船岸联系人交换对象、时间、风险、拟采取措施和授权人。不能由小懿替代船长、码头值班负责人或法定责任岗位作最终决定。

### 交班记录最少要包含什么？

至少应让接班人能够识别当前船舶与作业状态、未解除风险、临时控制措施、待确认事项、责任岗位、最后可信时间和下一检查点。记录应与企业安全管理体系和现场交班制度一致。

## 适用边界

ISM 主要面向船舶及公司安全管理体系。本摘要可以帮助小懿解释船岸职责与风险管理原则，但不能把船公司 SMS 直接替代港口安全生产制度，也不能据此自动批准生产动作。
