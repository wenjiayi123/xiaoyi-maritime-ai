# 船舶进出港与通航异常处置库

## 船舶晚到导致泊位冲突，该如何处理

关键词：船舶晚到、ETA 延误、泊位冲突、ETB 调整、船期延误、靠泊计划。

适用情况：船舶实际到港时间晚于计划，导致原泊位窗口被占用，影响后续船舶靠泊和作业计划。

处置步骤：

1. 确认船舶最新 ETA、锚地位置、引航窗口和海事限制。
2. 核对当前泊位占用、后续船舶优先级、作业量和合同服务等级。
3. 评估是否调整泊位、顺延 ETB、改靠相邻泊位或安排临时锚泊等待。
4. 同步船公司、船代、引航、拖轮、堆场计划和岸桥计划。
5. 重新计算岸桥分配、堆场出箱节奏和闸口预约影响。
6. 对受影响船舶生成调整记录，保留原因、时间、责任方和审批人。

注意边界：不得只按先到先靠处理，应结合船舶安全、合同等级、货物紧急程度、作业资源和整体港区拥堵情况综合判断。

## 船舶靠泊时强风增大，该如何处理

关键词：强风、靠泊、拖轮、引航、横风、风力超限、靠泊中止。

适用情况：船舶靠泊过程中风力突然增大，影响操纵安全和系泊安全。

处置步骤：

1. 立即确认实时风速、风向、流速、潮位和能见度。
2. 听从引航员和船长判断，必要时增加拖轮或暂停靠泊。
3. 通知泊位现场停止非必要人员靠近前沿区域。
4. 评估船舶受风面积、吃水、载货状态和泊位空间。
5. 若超过安全阈值，安排船舶回锚地或等待下一安全窗口。
6. 记录风速数据、指令时间、拖轮动作和最终靠泊结果。

注意边界：强风靠泊属于高风险操作，小懿只能给流程建议，最终由引航、船长、VTS 和港口调度共同确认。

## 船舶走锚，该如何处理

关键词：船舶走锚、锚地、VTS、拖轮、碰撞风险、应急通航。

适用情况：锚泊船舶受风流影响偏离锚位，可能影响航道或邻近船舶安全。

处置步骤：

1. VTS 立即确认 AIS 轨迹、锚位偏移、风流条件和周边船舶距离。
2. 通过 VHF 联系船舶，确认主机、锚机、值班和船长到位情况。
3. 通知附近船舶加强避让，必要时设置临时安全警戒区。
4. 调派拖轮待命或协助控制船位。
5. 根据风险决定重新抛锚、起锚移位或进港避风。
6. 事后记录轨迹、通信、气象、拖轮动作和风险影响。

## 缆绳断裂或系泊异常，该如何处理

关键词：缆绳断裂、系泊异常、船舶位移、靠泊安全、码头前沿。

适用情况：靠泊船舶因风浪、涌浪、潮汐或缆绳状态导致缆绳断裂、松缆、船体位移。

处置步骤：

1. 立即撤离前沿无关人员，避免断缆回弹伤人。
2. 通知船方、值班长、调度和安全员。
3. 检查船舶位移、舷梯、装卸设备与船体距离。
4. 必要时暂停岸桥、装卸臂、岸电和人员上下船。
5. 请求船方重新带缆，必要时安排拖轮顶推稳船。
6. 恢复作业前确认系泊状态、通道安全和设备安全距离。

## 船舶触碰码头或轻微碰撞，该如何处理

关键词：触碰码头、船舶碰撞、码头结构、护舷、船体损伤、事故报告。

适用情况：靠离泊过程中船体触碰护舷、码头结构、岸桥或其他船舶。

处置步骤：

1. 立即停止相关靠泊或装卸动作，确认人员安全。
2. 检查船体、护舷、码头结构、设备和管线是否受损。
3. 通知海事、港口安全、船方、保险和相关业务部门。
4. 保留视频、AIS、VTS、引航记录、气象和现场照片。
5. 评估是否影响继续靠泊、装卸或离港。
6. 出具初步事件报告，进入事故调查和责任认定流程。

## 大雾导致封航或限航，该如何处理

关键词：大雾、封航、限航、能见度、VTS、船期延误、航道管制。

适用情况：能见度低于通航安全要求，海事或 VTS 对港区进出港实施限制。

处置步骤：

1. 确认能见度、封航范围、预计恢复时间和受影响船舶清单。
2. 暂停高风险进出港计划，调整 ETA、ETB、ETD。
3. 优先保障已靠泊船舶安全和码头生产连续性。
4. 通知船公司、船代、拖轮、引航、堆场和闸口。
5. 对闸口预约、堆场出箱和岸桥排班进行滚动调整。
6. 恢复通航后按安全优先级和作业影响重新排序。
