# IMO《国际海运固体散装货物规则》（IMSBC Code）官方发布页摘要

## 来源定位

- 发布机构：International Maritime Organization（IMO）
- 官方 URL：https://www.imo.org/en/ourwork/safety/pages/cargoesinbulk-default.aspx
- 核验日期：2026-07-15
- 内容范围：`official_summary`，为 IMO 固体散装货物专题页摘要和规则定位，不是 IMSBC Code 最新完整版本。
- 法律属性：通过 SOLAS 体系实施的强制性规则框架；具体货物组别、附表、试验和装运条件以现行规则及主管机关要求为准。
- 版权边界：不摄取付费规则正文、货物附表、试验程序或大段原文。

## 适用范围

IMSBC Code 面向非包装固体散装货物的安全积载和运输，关注结构载荷、货物特性、液化、化学危险、粉尘和信息申报等风险。它不等同于 IMDG Code，后者主要覆盖包装形式危险货物。

## 关键知识

- 查询前应确认货物准确运输名称、组别、含水或危险特性、舱况和装港条件。
- 货物申报、抽样与试验、适运水分限制以及船长接受装货决定构成相互关联的控制链。
- IMSBC Code 定期修订，旧版货物附表或限值不可直接用于当前航次。

## 问答边界

本摘要只能提供分类思路和核验清单；不得给出具体货物的运输水分极限、试验合格结论、装船许可或豁免。高风险货物必须由现行规则、合格实验室资料、船舶文件和主管机关决定共同支撑。
