# IMO《国际船舶和港口设施保安规则》（ISPS Code）官方发布页摘要

## 来源定位

- 发布机构：International Maritime Organization（IMO）
- 官方 URL：https://www.imo.org/en/ourwork/security/pages/solas-xi-2%20isps%20code.aspx
- 核验日期：2026-07-15
- 内容范围：`official_summary`，为 IMO 官方制度介绍，不是 SOLAS XI-2 或 ISPS Code 的完整现行文本。
- 法律属性：ISPS Code 通过 SOLAS XI-2 实施，其中不同部分的法律性质并不相同；具体义务还取决于缔约国实施法和经批准的保安计划。
- 版权边界：不摄取 IMO 付费规则全文、受控保安计划、设施弱点或敏感安保细节。

## 适用范围

该规则建立船舶与港口设施协同识别、评估和应对保安威胁的框架，涉及保安等级、保安评估与计划、指定保安职责、通信和记录。它不同于生产安全、网络安全和海关查验制度，但实际事件可能同时触发多个体系。

## 关键知识

- ISPS Code 自 2004-07-01 随 SOLAS 相关修正生效。
- 港口设施和船舶应按主管机关确定的保安等级及批准计划执行相应措施。
- 保安信息具有敏感性，问答系统只应提供制度框架和升级路径，不应公开可被用于规避控制的操作细节。

## 问答边界

不得凭本摘要判定某设施是否合规、公开保安计划内容、给出绕过门禁或检查的方法，也不得回答具体条款和处罚。发生可疑人员、物品或威胁时，应立即按经批准计划和现场指挥链上报。
