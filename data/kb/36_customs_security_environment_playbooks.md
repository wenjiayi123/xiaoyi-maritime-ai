# 口岸、安全、环保与网络异常处置库

## 海关查验滞留影响装船，该如何处理

关键词：海关查验滞留、查验、放行异常、装船延误、监管状态、海关布控。

适用情况：出口箱因查验或监管状态未放行，影响装船计划。

处置步骤：

1. 确认箱号、提单号、报关单、查验状态和计划装船时间。
2. 暂停该箱装船指令，避免误装未放行货物。
3. 通知货代、报关行、船代、船公司和码头计划。
4. 评估是否调整装船顺序或替换箱位。
5. 查验完成后核对放行状态再恢复装船。
6. 记录监管状态、通知时间、调整动作和责任方。

## VGM 重量不符，该如何处理

关键词：VGM不符、重量异常、核验总重、配载、装船限制、SOLAS。

适用情况：集装箱申报 VGM 与实际称重、系统记录或配载要求不一致。

处置步骤：

1. 暂停该箱装船或进场放行。
2. 核对箱号、订舱、提单、称重记录和 VGM 报文。
3. 联系货主、货代或船公司确认修正 VGM。
4. 更新系统后重新进行配载安全校验。
5. 涉及危险品或重箱时提高复核等级。
6. 保留称重数据、修正记录和审批痕迹。

## 危险品泄漏，该如何处理

关键词：危险品泄漏、DG泄漏、危险品箱冒烟、异味、漏液、包装破损、IMDG、UN编号、隔离、消防、应急处置。

适用情况：危险品箱、化工品或液体货物出现泄漏、异味、冒烟、包装破损。

处置步骤：

1. 立即隔离现场，撤离无关人员并设置警戒区。
2. 查询 UN 编号、危险品类别、MSDS 和隔离要求。
3. 通知消防、安全、海事、环保和危险品负责人。
4. 禁止无防护人员接近，避免火源和不当冲洗。
5. 根据物质性质选择围堵、吸附、通风、冷却或转移。
6. 保留照片、视频、传感器、处置记录和外部通报记录。

## 港区火灾，该如何处理

关键词：火灾、失火、着火、起火、火情、冒烟、浓烟、消防、烟雾、爆燃、人员疏散、危险品、停电。

适用情况：堆场、仓库、设备、车辆、岸电、危险品或办公区域发生火情。

处置步骤：

1. 立即报警并启动消防应急预案。
2. 疏散人员，切断相关能源和设备运行。
3. 判断火源、货物类型、危险品和相邻风险。
4. 建立警戒区，保障消防通道。
5. 通知消防、港口安全、调度、海事和管理值班。
6. 火情控制后开展复燃监测、损失评估和事故调查。

## 油污泄漏或水域污染，该如何处理

关键词：油污泄漏、漏油、溢油、油品泄漏、水域污染、围油栏、吸油毡、MARPOL、环保通报。

适用情况：船舶、码头、管线或车辆导致油品进入水域或地面排水系统。

处置步骤：

1. 立即确认泄漏源、泄漏量、扩散方向和水文条件。
2. 停止相关作业并切断泄漏源。
3. 布设围油栏、吸油毡或导流拦截措施。
4. 通知环保、海事、安全和应急单位。
5. 收集污染物并按规定处置。
6. 记录污染范围、处置材料、监测结果和通报流程。

## 网络攻击或账号异常，该如何处理

关键词：网络攻击、账号异常、异常登录、权限滥用、勒索、TOS安全、接口异常。

适用情况：TOS、PCS、设备系统或账号出现异常登录、权限异常、接口异常或勒索风险。

处置步骤：

1. 立即隔离异常账号、终端或接口，保留日志。
2. 判断是否影响生产系统、自动化设备、闸口或能源系统。
3. 暂停高风险自动指令，切换人工确认。
4. 通知 IT 安全、系统负责人和运营值班。
5. 检查账号权限、接口调用、数据篡改和横向移动风险。
6. 恢复前完成安全确认，恢复后形成事件报告和加固措施。

## 粉尘超标或环保告警，该如何处理

关键词：粉尘超标、环保告警、散货码头、喷淋、挡风网、道路清扫。

适用情况：散货作业中粉尘监测超限，可能引发环保风险和投诉。

处置步骤：

1. 确认监测点、超标浓度、风向、风速和作业货种。
2. 降低或暂停高扬尘作业。
3. 启动喷淋、雾炮、封闭皮带和道路清扫。
4. 检查挡风网、料仓、转运点和车辆苫盖。
5. 通知环保负责人和现场调度。
6. 保留监测曲线、作业记录和治理动作。

## 作业人员受伤，该如何处理

关键词：人员受伤、有人受伤、伤人、工伤、急救、HSE、摔伤、夹伤、触电、机械伤害、车辆事故。

适用情况：港区作业人员发生摔伤、碰撞、夹伤、触电、车辆伤害或其他人身伤害。

处置步骤：

1. 立即停止相关作业，保护人员生命安全。
2. 呼叫急救和现场 HSE 人员。
3. 隔离事故区域，防止二次伤害。
4. 保留现场、视频、设备状态和作业许可。
5. 通知值班长、安全部门和管理人员。
6. 后续开展事故调查、整改和复工确认。
