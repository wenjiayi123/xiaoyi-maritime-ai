# IMO 国际海运危险货物规则（IMDG Code）

## 来源定位

- 发布机构：International Maritime Organization（IMO）
- 官方安全专题页：https://www.imo.org/en/ourwork/safety/pages/dangerousgoods-default.aspx
- 官方出版信息：https://www.imo.org/en/publications/pages/imdg%20code.aspx
- 当前出版信息：IMDG Code 2024 Edition，含 Amendment 42-24；自 2026-01-01 起强制适用
- 核验日期：2026-07-12
- 资料性质：IMO 官方页面事实摘要；不复制 IMDG Code 正文、危险货物表或隔离规则，不替代有权使用的现行规则版本。

## 已核验事实

- IMDG Code 用于协调包装形式危险货物的安全海运并防止环境污染，涉及包装、集装箱运输、积载以及不相容物质隔离等要求。
- SOLAS 第 VII 章规定包装危险货物运输应符合 IMDG Code 的相关规定；MARPOL 附则 III 与包装有害物质海运污染预防相关。
- IMO 出版页面说明 2024 版含 Amendment 42-24，并自 2026-01-01 起强制适用；实施时必须确认实际使用版本和主管机关要求。

## 一线处置问答

### 危险品箱出现渗漏或异味，能否先移到普通堆区？

不能凭经验直接转移。立即停止无关作业、控制人员接近并从上风向处置；识别箱号、UN 编号、正确运输名称、危险类别和应急资料；通知危险货物、安全、消防和环境责任岗位；按现场预案确定警戒、泄漏控制、隔离和转移方案。未经授权不得开箱、冲洗、混装或转入普通箱区。

### 小懿能否只根据品名判断隔离位置？

不能。隔离必须依据经核验的 UN 编号、危险类别、附加风险、包装组、数量、积载和隔离条目以及当前场区条件，并使用有权访问的现行 IMDG Code 和现场制度复核。

## 适用边界

本文件仅支持识别处置要素和风险边界。具体分类、包装、标记、单证、积载、隔离、应急响应和豁免必须查阅现行有权版本及主管机关、港口和企业制度。
