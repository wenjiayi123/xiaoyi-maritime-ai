# 港口现场事故口语问法

## 港口失火怎么办

关键词：港口失火、港区火灾、着火、起火、火情、消防、人员疏散。

适用情况：用户用“港口失火”“码头着火”“港区起火”“有火情”等口语问法描述港区火灾。

处置步骤：

1. 立即报警并启动港区消防应急预案。
2. 先疏散人员，封控火场周边，保障消防通道畅通。
3. 切断相关电源、油气源、岸电、充电设备或高风险设备运行。
4. 判断火源位置、燃烧物、相邻货物、危险品、油品和风向扩散风险。
5. 通知消防、港口安全、现场调度、海事、环保和值班管理人员。
6. 火情控制后进行复燃监测、损失评估、证据留存和事故复盘。

## 码头着火怎么办

关键词：码头着火、码头起火、泊位火灾、岸桥火情、前沿火灾、消防。

适用情况：泊位前沿、岸桥、装卸区域、车辆或设备附近出现火情。

处置步骤：

1. 立即停止受影响泊位、岸桥、车辆和邻近装卸作业。
2. 疏散前沿人员，划定警戒区，避免无关人员靠近。
3. 判断是否涉及船舶、岸电、燃油、危险品、冷藏箱或电气设备。
4. 通知消防、船方、调度、安全员、海事和设备负责人。
5. 根据风险调整靠离泊、岸桥分配、道路通行和堆场作业。
6. 保留视频、告警、设备状态、作业指令和现场处置记录。

## 堆场冒烟怎么办

关键词：堆场冒烟、箱区冒烟、烟雾、火情、冷藏箱、电池、危险品箱。

适用情况：堆场、箱区、冷藏箱、危险品箱、车辆或设备出现烟雾、焦味或疑似燃烧。

处置步骤：

1. 立即暂停该箱区周边作业，设置警戒区并疏散无关人员。
2. 确认冒烟对象：箱号、箱型、货类、冷藏箱状态、危险品类别和堆位。
3. 禁止盲目开箱、冲水或移动，先由消防和专业人员判断风险。
4. 切断相关供电或充电设备，隔离相邻危险品、冷藏箱和高价值货物。
5. 通知消防、安全、堆场调度、船公司或货代，并保留监控和传感器记录。
6. 处置后检查复燃、扩散、污染和货损风险，再决定是否恢复作业。

## 仓库起火如何处理

关键词：仓库起火、仓库火灾、库区火情、货物燃烧、消防、人员疏散。

适用情况：港区仓库、监管仓、保税仓、冷库或普通库区发生火情。

处置步骤：

1. 立即报警，启动仓库消防联动和人员疏散。
2. 切断仓库电源、叉车充电、照明和相关高风险设备。
3. 判断库存货类、危险品、冷链货、包装材料和相邻库区风险。
4. 保障消防车道、消火栓、喷淋、泡沫或气体灭火系统可用。
5. 通知仓储负责人、安全、海关监管、消防、客户和管理值班。
6. 火情控制后清点货损、监管状态、库区结构和复工条件。

## 危险品箱冒烟怎么办

关键词：危险品箱冒烟、DG冒烟、危险品泄漏、异味、发热、IMDG、UN编号、MSDS。

适用情况：危险品箱、化工品或液体货物出现冒烟、异味、发热、泄漏或包装异常。

处置步骤：

1. 立即隔离危险品箱，撤离无防护人员并扩大警戒范围。
2. 查询 UN 编号、IMDG 类别、MSDS、隔离要求和灭火禁忌。
3. 禁止盲目开箱、拖移、冲水或靠近火源。
4. 通知消防、危险品负责人、安全、海事、环保、船公司或货代。
5. 根据物质性质选择冷却、通风、围堵、吸附、转移或专业处置。
6. 全程记录箱号、堆位、温度、烟雾、气味、处置动作和外部通报。

## 港口漏油怎么办

关键词：港口漏油、码头漏油、溢油、油污泄漏、水域污染、围油栏、MARPOL。

适用情况：船舶、车辆、管线、装卸臂、油品码头或设备导致油品进入地面、水域或排水系统。

处置步骤：

1. 立即确认泄漏源、油品类型、泄漏量、扩散方向和是否进入水域。
2. 停止相关装卸、输油、车辆或设备作业，切断泄漏源。
3. 布设围油栏、吸油毡、导流拦截或临时围堵措施。
4. 通知环保、海事、安全、码头调度和应急处置单位。
5. 收集污染物并按规定处置，避免油污进入雨水管网或航道。
6. 记录污染范围、处置材料、监测结果、通报时间和责任链。

## 港区有人受伤怎么办

关键词：港区有人受伤、人员受伤、工伤、急救、HSE、机械伤害、车辆事故。

适用情况：港区作业人员、司机、承包商或访客发生摔伤、夹伤、碰撞、触电、车辆伤害等情况。

处置步骤：

1. 立即停止相关作业，优先保护生命安全。
2. 呼叫急救、现场 HSE、安全员和值班负责人。
3. 隔离事故区域，防止车辆、机械、吊具或电气造成二次伤害。
4. 在不影响救援的前提下保留现场、视频、设备状态和作业许可。
5. 通知相关部门、承包商或管理人员，必要时启动事故报告流程。
6. 后续开展原因调查、整改、复工确认和培训复盘。

## 港区车辆事故怎么办

关键词：港区车辆事故、集卡碰撞、车辆剐蹭、交通事故、人员受伤、道路封控。

适用情况：港区集卡、拖车、叉车、正面吊、社会车辆或公务车发生碰撞、剐蹭、侧翻或伤人。

处置步骤：

1. 立即停车并封控事故道路，优先确认人员是否受伤。
2. 如有人受伤，先呼叫急救并防止二次碰撞。
3. 通知港区交通、安全、调度、设备和管理值班。
4. 保留视频、车牌、司机信息、行驶路线、设备状态和现场照片。
5. 根据影响调整闸口、道路、堆场设备和车辆分流。
6. 完成事故处理、责任认定、道路恢复和复盘整改。
