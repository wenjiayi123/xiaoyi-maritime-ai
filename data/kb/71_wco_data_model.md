# WCO 数据模型（WCO Data Model）

## 来源定位

- 发布机构：World Customs Organization（WCO，世界海关组织）
- 唯一官方 URL：https://www.wcoomd.org/DataModel
- 核验日期：2026-07-11
- 资料性质：WCO 官方数据模型介绍与技术资料入口，说明跨境监管数据标准化和互操作用途，不等于任一成员海关已经采用的本地接口规范。
- 版权边界：本文件仅概括官方页面公开的定位、组成和用途，不复制数据模型手册、消息定义或受许可限制的技术内容；实施时应通过 WCO 认可渠道取得有权使用的版本。

## 已核验事实

- WCO Data Model 面向跨境数据交换提供统一的数据语言，用于支持海关与其他跨境监管机构之间的互操作。
- 该模型由结构化、协调、标准化且可复用的数据定义和电子消息组成，旨在满足边境管理中的业务与法律需求。
- WCO Data Model 可支撑 Single Window（单一窗口）实施，并通过协调数据集减少进出口和过境流程中的重复数据要求。
- 官方页面提供数据模型技术资料、维护流程、数据协调以及电子消息相关入口。

## 适用边界

WCO Data Model 是国际协调基础，不是中国海关、某一单一窗口或某个港口生产系统的直接接口。真实接入必须核对目标主管机关采用的模型版本、国家扩展、代码表、消息结构、必填规则、签名认证、回执和错误处理。仅命中本索引时，小懿可以解释数据协调思路，但不得生成或提交未经主管机关规范验证的申报报文。
