# 码头生产与系统异常处置库

## 堆场拥堵导致装卸效率下降，该如何处理

关键词：堆场拥堵、堆场利用率、翻箱率、装卸效率下降、水平运输等待、箱区饱和。

适用情况：堆场占用率过高、翻箱率上升、水平运输等待，导致岸桥不断档风险增加。

处置步骤：

1. 确认拥堵箱区、箱型、航线、船名航次和堆存结构。
2. 暂停低优先级进场预约，优先释放即将装船或提箱的关键箱。
3. 调整堆场分配策略，启用备用箱区或临时缓冲区。
4. 对高翻箱区执行预翻箱、移箱或重组。
5. 协调闸口、拖车和船公司加快提箱或疏运。
6. 记录拥堵原因、影响船舶、处置动作和恢复时间。

## 闸口车辆排队过长，该如何处理

关键词：闸口排队、集卡拥堵、预约窗口、OCR、放行异常、提箱高峰。

适用情况：外集卡排队时间过长，影响港区道路、堆场作业和客户服务。

处置步骤：

1. 判断排队来自预约集中、OCR 异常、海关放行、设备故障还是堆场拥堵。
2. 临时增开闸道或人工复核通道。
3. 对无放行、无预约、信息不符车辆引导至异常处理区。
4. 调整预约窗口，错峰分流外集卡。
5. 同步堆场设备和箱区，避免车辆入场后继续等待。
6. 发布客户提示，记录排队时长、处理量和异常原因。

## TOS 系统宕机或响应极慢，该如何处理

关键词：TOS宕机、TOS响应慢、系统不可用、消息队列堆积、降级运行、离线作业。

适用情况：TOS 无法正常响应，影响船舶计划、堆场指令、闸口放行或设备调度。

处置步骤：

1. 立即冻结高风险自动派发和批量指令。
2. 判断故障范围：船舶计划、堆场、闸口、EDI、设备接口或数据库。
3. 启动最小生产闭环，保留必要装卸、闸口和安全业务。
4. 使用离线记录或应急表单记录关键操作。
5. 通知 IT、调度、现场、客户服务和管理值班。
6. 系统恢复后进行数据补录、对账和审计核验。

注意边界：TOS 降级不能绕过海关放行、危险品限制、安全联锁和人工审批。

## EDI 报文异常或未到达，该如何处理

关键词：EDI异常、报文未到、舱单异常、船公司报文、数据不同步。

适用情况：船公司、海关、船代或码头之间的 EDI 报文未按时到达或字段错误。

处置步骤：

1. 确认报文类型、发送方、接收方、时间戳和错误码。
2. 核对船名航次、箱号、提单号、货名、重量、目的港等关键字段。
3. 联系发送方重新发送或修正报文。
4. 对受影响作业设置人工复核，不直接放行或装船。
5. 若影响船舶计划或闸口业务，通知调度和客户服务。
6. 保留原报文、错误日志、修正记录和处理人。

## OCR 误识别导致箱号不符，该如何处理

关键词：OCR误识别、箱号不符、车牌识别错误、封号不符、闸口异常。

适用情况：闸口或堆场 OCR 识别结果与预约、放行或单证信息不一致。

处置步骤：

1. 将车辆或箱子引导至异常复核区域。
2. 人工核对箱号、封号、车牌、预约号和放行状态。
3. 调取图片、视频和 OCR 原始识别结果。
4. 若是识别误差，人工修正并记录；若是单证不符，暂停放行。
5. 对频繁误识别设备检查摄像头角度、光照和算法阈值。
6. 对修正动作保留操作人、时间和原因。

## 岸桥故障导致船舶作业中断，该如何处理

关键词：岸桥故障、QC故障、桥吊停机、船舶作业中断、岸桥效率下降。

适用情况：岸桥机械、电气、吊具或控制系统故障，导致船舶装卸暂停。

处置步骤：

1. 立即确认故障岸桥编号、作业舱位、吊具状态和人员安全。
2. 暂停相关作业区域，防止吊具、箱体或人员风险。
3. 维修人员判断故障类型和预计修复时间。
4. 调度评估是否调整岸桥分配或转移作业舱位。
5. 同步船舶计划、堆场计划和船公司。
6. 记录停机时间、故障原因、维修动作和效率影响。

## AGV 或水平运输大面积异常，该如何处理

关键词：AGV故障、水平运输异常、车辆调度失败、路径拥堵、自动化码头。

适用情况：自动化水平运输设备无法正常接收任务、路径拥堵或大面积离线。

处置步骤：

1. 确认影响范围：单车故障、区域拥堵、调度系统异常或通信故障。
2. 暂停向异常区域继续派发任务。
3. 调整岸桥节奏，避免岸边堆积。
4. 启用备用车辆、人工接管或临时路线。
5. 检查通信、定位、地图、任务队列和充电状态。
6. 恢复后复盘任务积压、车辆空驶和岸桥等待时间。
