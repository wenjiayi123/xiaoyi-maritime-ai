# Support

Use GitHub Discussions or a feature issue for usage questions and GitHub Issues for reproducible defects after the repository is published. Include the version, runtime mode, reproduction steps, and `X-Request-ID`; remove credentials, private port data, and internal hostnames.

This open-source project does not provide an uptime, safety, or response-time guarantee. A real port deployment needs an identified service owner, incident rotation, backup owner, security contact, and site-specific acceptance plan.

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
