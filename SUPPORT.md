# 支持 · Support

仓库公开后，使用 GitHub Discussions 或 Feature Issue 讨论用法，使用 Bug Issue 报告可复现缺陷。请提供版本、运行模式、复现步骤和 `X-Request-ID`，并删除凭据、私有港口数据和内部主机名。

After publication, use GitHub Discussions or a feature issue for usage questions and a bug issue for reproducible defects. Include the version, runtime mode, reproduction steps, and `X-Request-ID`; remove credentials, private port data, and internal hostnames.

本开源项目不承诺可用性、安全结果或响应时间。真实港口部署必须指定服务负责人、事件响应轮值、备份负责人、安全联系人和站点验收计划。

This open-source project provides no uptime, safety-outcome, or response-time guarantee. A real port deployment needs an identified service owner, incident rotation, backup owner, security contact, and site-specific acceptance plan.

漏洞请按 [SECURITY.md](SECURITY.md) 私下报告。Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
