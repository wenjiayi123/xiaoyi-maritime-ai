# 行为准则 · Code of conduct

我们致力于营造尊重、无骚扰的协作环境。请保持建设性、善意理解他人、保护私有运营数据，并用可复现证据讨论技术主张。

We are committed to a respectful, harassment-free collaboration environment. Be constructive, assume good faith, protect private operational data, and critique technical claims with reproducible evidence.

不可接受的行为包括骚扰、威胁、歧视性语言、公开他人隐私、泄漏凭据或港口数据，以及明知故犯地把合成结果表述为生产事实。

Unacceptable behavior includes harassment, threats, discriminatory language, publishing another person's private information, leaking credentials or port data, and knowingly representing synthetic results as production facts.

为保护贡献者和用户，维护者可以编辑或删除内容并限制参与。行为问题请私下报告给仓库所有者；仓库公开时将配置长期私有联系渠道。

Maintainers may edit or remove contributions and restrict participation when needed to protect contributors or users. Report conduct issues privately to the repository owner; a permanent private channel will be configured when the repository is published.
