# 生产系统接入后实时问题 / Live Questions After Integration

本文件中的问题问法可以使用，但目前若没有接入真实生产系统，小懿必须明确说明“无法确认当前实绩”并指出所需数据源。后续按现有数据契约连接生产接口后，问题本身无需改变。

## TOS / 泊位计划 / 生产计划

- 今天港口实际吞吐量是多少？
- 当前有多少艘船在港？
- 海盛轮什么时候靠泊？
- IMO 号为 1234567 的船当前处于哪个挂靠里程碑？
- 这条船的最新 ETA、ETB 和 ETD 分别是什么？
- B03 泊位当前由哪条船占用？
- 未来24小时有哪些待靠船？
- 当前哪条船可能错过泊位窗口？
- 3号泊位前船还剩多少作业量？
- 当前岸桥计划与船舶配载计划是否一致？
- 哪些出口箱还未按计划装船？
- 当前未闭环生产指令有哪些？

## PCS / 海关 / 单证 / 放行

- 箱号 MSKU1234567 现在到哪了？
- 这个箱当前是进闸、在场、装船还是出闸状态？
- 这个箱海关是否已经放行？
- 这个箱码头是否已经放行？
- 订舱号对应的 VGM 是否已经接收？
- 舱单报文是否已回执成功？
- 哪些箱因为单证问题被拦截？
- 当前有哪些查验箱影响装船计划？
- D/O 是否已经生效？
- 单证修改后生产系统是否已经同步？

## AIS / VTS / 引航 / 拖轮

- 目标船舶当前 AIS 位置在哪里？
- 目标船舶预计何时到达引航站？
- 当前引航计划是否已经确认？
- 拖轮是否已经到位？
- 当前航道窗口能否满足该船吃水要求？
- 这条船为什么还没有获准进港？
- 当前靠泊条件还缺哪一项？
- 船方 ready 状态是否已经确认？

## EAM / 设备系统 / AGV 车队

- AGV-023 现在在线吗？
- AGV-023 当前电量是多少？
- AGV-023 当前执行哪个任务？
- QC-03 当前运行状态是什么？
- QC-03 最近30分钟有哪些告警？
- QC-03 维修工单进展如何？
- 当前有哪些设备停机？
- 哪些设备已超过计划维护时间？
- 当前 AGV 车队可用率是多少？
- 哪台备用设备可以接替当前任务？

## EMS / 计量 / 岸电

- 3号泊位岸桥现在能耗多少？
- QC-03 最近30分钟单位作业能耗是多少？
- 当前岸电接入船舶有几艘？
- 当前岸电利用率是多少？
- 哪个设备是本班能耗异常点？
- 当前峰值需量是多少？
- 当前单位 TEU 能耗和碳排是多少？
- 哪条能耗告警尚未确认？
- 计量数据是否存在缺失或质量异常？

## 闸口 / 预约 / OCR

- 现在南闸口实际排队多久？
- 南闸口未来30分钟预约到车多少辆？
- 当前开放车道有几条？
- 哪条车道处理时间异常？
- 是否达到备用车道增开阈值？
- 当前有哪些 OCR 识别失败车辆？
- 哪些车辆因为箱号或封志不一致被拦截？
- 场内接纳能力是否支持增加进闸流量？

## 接入时必须返回的最小信息

每条真实答案至少应包含：业务对象唯一标识、数据来源系统、事件时间、数据质量状态、当前值或状态、判断依据、责任岗位和需要人工确认的动作。
