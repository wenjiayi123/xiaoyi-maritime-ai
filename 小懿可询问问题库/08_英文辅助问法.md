# 英文辅助问法 / English Auxiliary Questions

## Daily Operations

- What is the current port operating status?
- Is the port busy today?
- How many vessels are currently in port?
- What is today's accumulated throughput?
- What should this shift handle first?
- Please generate a shift handover summary.
- Please list all open issues by responsible role.
- How do I report a terminal incident?
- What should be included in a shift handover record?
- How do I know whether a task is fully closed?

## Vessel & Berth

- What do ETA, ETB and ETD mean?
- What is the difference between ETA and ETB?
- When will this vessel berth?
- What conditions must be confirmed before berthing?
- What does “pilot on board” mean?
- What does “tug made fast” mean?
- What is a berth window?
- How does vessel draft affect berthing?
- What should be recorded after vessel departure?
- Please explain the complete port-call process.

## Useful Bilingual Commands

- 请按先安全、后恢复给出处置步骤。 / Give response steps in the order of safety first, then recovery.
- 请列出依据与来源。 / List the evidence and sources.
- 请标明数据时点。 / State the data timestamp.
- 请标明需要谁确认。 / Identify the required approver.
- 请不要猜测实时数据。 / Do not guess live operational data.
- 请整理成交班摘要。 / Convert this into a shift handover summary.
- 请生成现场核对清单。 / Generate a frontline verification checklist.
- 请用一分钟口头汇报。 / Turn this into a one-minute verbal briefing.
