## RL为何仍不如MPC，以及本轮做了什么

本轮保留五档动作和原成本系数。修复了合成需求冲击只影响结果、却永不进入延迟公开观测的问题：冲击发生后，只有等同样的7天/14天延迟到达，策略才看见它。这个观测合同变化明确记录，不与旧协议分数混算。

容量归一化仍按固定的常态7天延迟代理建立；14天发布延迟压力只改变需求观测可用性，不改变设备的物理容量。容量是冻结工程假设，不能声称所有容量参数都来自对应历史时刻已发布的现场测量。

新增比较与训练：

1. PID在12组增益中按2025验证集整定。
2. 保留原三步MPC，新增14步动态规划MPC和稳健MPC，仍按验证集选强基线；MPC14最终胜出。它使用声明模型、离散队列网格和预测量量化，不使用未来真实到达量。
3. 场景均衡Double DQN：正常训练热身后混入四类场景，保留大队列状态信息；gamma=1、成本正线性缩放，取消奖励/目标裁剪。
4. MPC回归预训练Double DQN：另存预训练结束时的纯模仿快照，避免把老师或回退的表现包装成RL。
5. 额外验证集开发：分类模仿、独立价值/优势头的dueling Double DQN、真实TD更新与辅助模仿损失；该候选使用gamma=0.97，作为单独协议变化记录，不宣称单因素因果归因。

三个RL算法各五个种子、每次40,000步，共**600,000次实际RL交互**。另有十份纯模仿快照；合计25份封存神经网络文件，不把它们叫作25次独立RL训练。所有神经策略在留出评估时直接用网络决策，没有在线MPC回退。
