# 小懿与 Hi-Dolphin 官方公开能力差距矩阵

核对日期：2026-08-13。

## 结论先行

当前不能声明“小懿已经全面超越中远海运 Hi-Dolphin”。双方没有共同的独立模型评测、同等实时数据、相同用户负载和可比的生产效果研究。小懿当前可证明的优势是开源可复现、哈希化证据、失败候选保留、现场数据缺失时失败关闭，以及明确的生产权限准入；公开规模、实时全球港航数据、智能体数量和企业部署仍明显不足。

机器可读原始矩阵见 [`data/competitive/hi_dolphin_public_gap_v1.json`](../data/competitive/hi_dolphin_public_gap_v1.json)。

## 小懿应当如何“超过”

不是继续堆算法名称，而是逐项通过同口径门禁：

1. 在共同、独立的MaritimeBench或等价盲测上发布分域准确率、失败题和哈希。
2. 接入获授权AIS、港口、气象和船期数据，验证新鲜度、字段映射、漂移、停机和回退。
3. 对工具调用发布任务成功率、错误调用率、注入攻击阻断率和人工确认覆盖率。
4. 对ETA/等泊/能耗等任务采用时间盲测，并击败季节性、规则、运筹或控制强基线。
5. 完成真实试点、并发负载、可用性SLO、用户研究和业务结果核验。
6. 保持小懿当前可核验优势：本地运行、开源证据、不可覆盖历史、失败候选、权限默认关闭和可回滚发布。

在这些门禁通过前，安全表述只能是：

> 小懿在本仓库展示了更强的开源复现性与显式失败关闭边界；尚未证明整体能力、数据规模或生产效果超过 Hi-Dolphin。
