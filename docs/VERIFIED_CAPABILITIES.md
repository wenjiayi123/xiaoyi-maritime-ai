# 小懿AI 工程能力与指标边界

## 系统能力概述

**小懿AI 港航开源生成式大模型与智能决策平台**

面向港口调度、法规检索与应急处置的可审计 AI 助手，构建“开源底座 +
稠密/稀疏 RAG + LoRA + 回答后证据报告”完整链路、跨轮问题改写、复杂问题
分治、官方来源注册表、辖区/生效日期证据路由、
逐项引用、主张—证据词面对齐和数字/日期完整性校验、普通无证据回答底部提示、
法规全文与实时数据核验边界；集成流式问答、只读能力编排、
JWT/RBAC、SQLite 审计及可替换港口数据契约。

▸ **生成式大模型工程**：针对16GB Intel Mac配置4B开源量化生成档，并以
17.29亿参数同架构开源模型建立可复现LoRA训练档；从15份人工整理来源及42条
人工审核监督样本构建 **841条**训练数据，按来源隔离为 **622/94/125**，
并排除 **212条**固定评测问题。完成Rank 96、Alpha 192、64步CPU LoRA，
训练 **104,595,456 / 1,825,170,432** 个参数（**5.730723%**）；
8例验证/测试loss分别下降 **43.55% / 40.49%**，产出PEFT
safetensors、209,218,240字节GGUF LoRA、训练报告和SHA-256；用
llama.cpp b10107 实测加载适配器，并跑通“RAG 检索 → LoRA 生成 →
回答后证据报告”的 `/api/chat` 链路。另用
0.6B本地向量模型为 **882 个**知识分块建立 **1024 维**本地稠密
向量索引。隔离loss下降是固定样本优化信号，不宣称4B已微调、回答准确率或
港口生产效果。

▸ **量化指标**：面向 **129 份港航资料、882 个可检索知识分块和 68 份
官方核验来源**，发布六套版本化固定基准，合计 **260 题**：v1 为 **40 题
检索 + 20 题证据策略**，其中 **35 题**发布测试分区包含 **24 题检索 +
11 题策略**；v2 为 **20 题多轮 + 20 题复杂拆解 + 20 题对抗边界**。
v3 为 **14 题真实问答决策就绪 + 16 题冲突/新鲜度/失败关闭保障**；v4
为 **6 题引用角色 + 6 题主张—证据词面对齐 + 8 题数字/日期/量值完整性**。
v5 为能源、船舶泊位、堆场闸口、班组协同、单证和设备 **6 类 × 10 题**
日常运营问答，并单列 **3 题**模糊澄清/实时数据边界；v6 建立 **15 个
业务域 × 26 种问题形式 = 390 个意图单元**和 **780 条正式/日常矩阵问法**，
以 **30 题**分域固定集逐项验收，并单列 **5 题**澄清、实时数据与官方全文
边界（v5/v6 边界题不重复计入260题）。
对 v1 的评测集、知识索引、来源注册表及核心策略代码等 **8 项关键工件**
进行 SHA-256 固化。在 24 题检索测试上，Hybrid Sparse 的 Hit@1/3/5 达
**100%/100%/100%**，同快照、同过滤 BM25-only 为
**95.83%/95.83%/95.83%**，首位命中率提升 **4.17 个百分点**，MRR
由 **0.9583** 提升至 **1.0000**（提升 **4.17 个百分点**）；官方来源
要求通过率、官方查询 Top-5 来源纯度和证据双哈希完整率均为 **100%**，
**7 个**显式本地辖区题路由 **7/7 正确**，**17 个**国际通用题保持
**17/17 无本地误路由**；条款级拒答、无依据回答阻断、辖区路由、法规
日期切换和实时数据边界等 **11 项证据策略测试 11/11 通过**；v2 的多轮
上下文改写、复杂问题分治和对抗性证据边界均 **20/20 通过**（v1/v2 均为
开发可见的仓库固定验收集）；v3 决策保障 **30/30 通过**，输出
`ready/partial/refused`、风险级别、阻断原因和下一步人工或系统动作
；v4 主张—证据对齐门禁 **20/20 通过**，可阻断有效编号指向无关内容及
证据外数字、日期和量值；v5 日常运营问答 **60/60 通过**，模糊问题澄清
与实时数据失败关闭 **3/3 通过**；v6 的 15 个业务域正式/日常固定题
**30/30 通过**，澄清、实时与官方全文边界 **5/5 通过**（六套题集均非第三方盲测、用户研究、
语义蕴含证明、生产安全认证或港口生产 KPI）。

▸ **工程化**：发布逐题 JSON 报告及评测集、知识索引、来源注册表和核心
策略代码 SHA-256，支持一条命令完整复跑；生产连接器默认离线，即使返回
`live_data_verified=true` 也必须继续通过清单、字段映射、质量、漂移、标定与
时区门禁，高风险任务保持人工确认，生产权限默认关闭。

▸ **港口实时数据与决策闭环**：设计 `port-realtime.v1` 可替换数据契约，覆盖
港口挂靠、AIS/VTS、泊位、设备、堆场、闸口、能源碳排、气象潮汐、安全维护和
治理审计 **10 个业务域、153 个规范字段**；实现 **2 秒**事件流、**5 个**因果
场景和 **168 台**设备对象，打通质量门禁、约束建议、两个不同身份审批、模拟
执行、审计和回滚。公共 AIS 只校准交通包络，其他港口量级与影响为工程模拟；
该闭环可证明换源前的接口与安全工程能力，不是现场实测、生产 KPI 或真实收益，
固定 `physical_dispatch_performed=false`、`production_authority=false`。

▸ **强化学习证据链**：保留原 19,735 行 UCI 能源基准并新增 409,887 行
五分钟级公开大规模基准（20.77 倍）与 NOAA 洛杉矶—长滩港区 710 个 AIS
实测分钟桶；实现 Q-learning、SARSA、Expected SARSA、Double Q-learning，
并与 PID、现场SOP固定规则两类非学习强基线同划分比较。使用三个固定种子、
时间顺序 70%/15%/15% 隔离、训练无渲染、测试后轨迹及数据/配置/profile/
模型/评估 SHA-256；报告均值、标准差和 Student-t 95% CI。按预声明验证集门禁，
四个RL候选均未稳定击败强基线，因此全部保留失败原因、`policy_admission=false`
且不声明策略优势（公开离线基准与校准沙箱，不是港口生产收益）。

## 指标解释与复核口径

- 这里现在确实面向17.29亿参数训练基座完成了64 step、Rank 96本机LoRA，
  实际训练1.046亿适配器参数，
  并记录8例验证/测试loss对照；它仍属于本机受限实验，
  不是完整收敛实验；默认 4B 生成档未微调，1.7B 适配器也不能挂到 4B。
- 监督训练集、可检索知识语料、固定评测题和运营沙箱仍是四类不同数据；
  LoRA 构建器先排除固定题并按来源隔离，不能把知识分块数或评测题数混称
  训练样本数。
- Hit@5 衡量正确来源是否出现在前 5 个结果，MRR 进一步惩罚正确来源排名靠后；
  因而 MRR 提升比“100% Hit@5”更能说明排序质量。
- BM25 基线与 Hybrid 使用同一索引、同一辖区过滤和同一 Top-5，Hybrid
  额外融合稀疏语义相似度、覆盖率、标题、来源质量和辖区重排。
- v2 验证的是确定性的对话改写、子问题覆盖、引用完整性和安全边界，不是对
  自由生成文本做主观“智能评分”，也不是法律正确率。
- 策略测试不是回答内容风格评分，而是检查该拒答时是否拒答、是否选对辖区与
  生效日期、是否把沙箱或历史文档冒充实时值。
- 35 题测试分区参与过 v1 发布验收和缺陷修复，所以只称“固定测试分区”，
  不称“独立盲测”或“完全未见留出集”。
- v2 的 60 题同样由项目维护且在开发中可见，不称“外部评测”。
- v3 的冲突检测是保守词面与元数据门禁；“未检出冲突”不等于事实或法律
  结论已经被证明。
- v4 是确定性的词面对齐和数字完整性门禁，不是自然语言语义蕴含、事实正确率
  或法律正确率；它解决的是“有引用但明显不支持”这一类可自动阻断的错误。
- v5 验证六类高频日常场景能否命中正确内部作业问答并通过引用门禁，不代表
  覆盖所有港口、设备型号、客户合同或现场制度；实时状态仍要求验证连接器。
- v6 的 390 个意图单元和 780 条矩阵问法用于系统化发现覆盖缺口；30 题
  固定分域样本通过不等于所有自然语言表达、所有港口或全部日常问题已被证明。

## 禁止超范围声明

- “检索准确率100%”或“AI回答准确率100%”：Hit@5 不是回答准确率。
- “4B 默认生成档已完成 LoRA 微调”：本机适配器使用同架构17.29亿参数训练基座。
- “LoRA 已证明港航生产效果提升”：固定隔离样本loss下降不等于回答准确率，
  仍需更大未见测试集、基座生成对照及未参与训练的港航业务人员盲评。
- “全球法规覆盖”“可替代法律审查”：来源覆盖有限且摘要不等于法规全文。
- “港口效率提升/成本下降”：本仓库没有港口生产对照实验。
- “实时接入TOS/AIS/VTS”：连接器契约已实现，但默认未接生产端点。
- “153 项真实港口数据”或“2秒港口实测”：153 是规范字段覆盖，2秒是模拟事件周期；独立公共观测仍只有登记的 AIS 分钟桶和能源基准原始行。
- “多智能体强化学习平台”：当前 RL Lab 是能源与 AIS 港口交通场景上的单策略
  表格型 RL 与 PID 对照，不是港口多智能体生产调度。
- “港口效率提升35.46%”：35.46% 是大规模公开家庭用电环境中 Expected SARSA
  的平均测试节费代理，使用实验电价，不是港口现场成本或效率。
