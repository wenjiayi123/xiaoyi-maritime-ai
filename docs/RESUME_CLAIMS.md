# 小懿AI 简历指标口径

## 推荐简历表述

**【工程】小懿AI 港航RAG与智能决策平台（独立全栈自研）**

面向港口调度、法规检索与应急处置的可审计 AI 助手，构建 Hybrid Sparse
RAG、官方来源注册表、辖区/生效日期证据路由、条款级拒答和实时数据失败关闭；
集成流式问答、只读能力编排、JWT/RBAC、SQLite 审计及可替换港口数据契约。

▸ **可复现实验**：基于 112 份港航资料、708 个可检索分块及 60
份官方核验来源，设计 60 题固定版本基准；在 35 题固定测试分区中，
24 个检索题上 Hybrid Sparse 的 Hit@1/3/5 达
**87.50%/100%/100%**，同快照、同过滤 BM25-only 为
**75.00%/95.83%/100%**，MRR 由 **0.8507** 提升至
**0.9236**；官方查询 Top-5 来源纯度、证据双哈希完整率、显式本地辖区
路由及国际问题无本地误路由均达到 **100%**；11 个证据策略测试实现条款级/无依据回答阻断、辖区路由、
法规日期切换与实时数据边界 **11/11 通过**（仓库固定验收集，非第三方
用户研究或港口生产 KPI）。

▸ **工程化**：发布逐题 JSON 报告及评测集、知识索引、来源注册表和核心
策略代码 SHA-256，支持一条命令完整复跑；生产连接器默认离线，未返回
`live_data_verified=true` 时失败关闭，高风险任务保持人工确认。

▸ **强化学习证据链**：保留原 19,735 行 UCI 能源基准并新增 409,887 行
五分钟级公开大规模基准（20.77 倍）与 NOAA 洛杉矶—长滩港区 710 个 AIS
实测分钟桶；实现 Q-learning、SARSA、Expected SARSA、Double Q-learning
与 PID 同划分比较，使用三个固定种子、时间顺序 70%/15%/15% 隔离、训练无
渲染、测试后轨迹及数据/配置/profile/模型/评估 SHA-256。大规模能源基准的
多种子平均测试优选为 Expected SARSA；原小基准和 AIS 校准场景均由 PID
三次胜出，所有算法平均投影约束违例为 0（公开离线基准与校准沙箱，不是港口
生产收益）。

▸ **技术栈**：Python + FastAPI + Pydantic + Hybrid Sparse/BM25/RAG
+ SSE/OpenAI-compatible Gateway + JWT/RBAC + SQLite + 原生
JavaScript/CSS + Docker + GitHub Actions + pytest

## 面试时可以直接解释

- 这里没有训练或微调 LLM；数据分为可检索知识语料、固定评测题和运营沙箱，
  三者不能混称“训练集”。
- Hit@5 衡量正确来源是否出现在前 5 个结果，MRR 进一步惩罚正确来源排名靠后；
  因而 MRR 提升比“100% Hit@5”更能说明排序质量。
- BM25 基线与 Hybrid 使用同一索引、同一辖区过滤和同一 Top-5，Hybrid
  额外融合稀疏语义相似度、覆盖率、标题、来源质量和辖区重排。
- 策略测试不是回答内容风格评分，而是检查该拒答时是否拒答、是否选对辖区与
  生效日期、是否把沙箱或历史文档冒充实时值。
- 35 题测试分区参与过 v1 发布验收和缺陷修复，所以只称“固定测试分区”，
  不称“独立盲测”或“完全未见留出集”。

## 不应写入简历

- “检索准确率100%”或“AI回答准确率100%”：Hit@5 不是回答准确率。
- “全球法规覆盖”“可替代法律审查”：来源覆盖有限且摘要不等于法规全文。
- “港口效率提升/成本下降”：本仓库没有港口生产对照实验。
- “实时接入TOS/AIS/VTS”：连接器契约已实现，但默认未接生产端点。
- “多智能体强化学习平台”：当前 RL Lab 是能源与 AIS 港口交通场景上的单策略
  表格型 RL 与 PID 对照，不是港口多智能体生产调度。
- “港口效率提升35.46%”：35.46% 是大规模公开家庭用电环境中 Expected SARSA
  的平均测试节费代理，使用实验电价，不是港口现场成本或效率。
