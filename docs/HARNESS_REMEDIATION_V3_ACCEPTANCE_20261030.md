## 单因素消融：找到了什么

每个种子读取同一份已封存模仿权重，优化器统一重置；固定同一回放、批次顺序、目标刷新频率和3,000次更新。七种条件各五种子，除了所列因素，其余保持相同。回放共60,300次仿真交互；35个网络共105,000次小批次更新，其中关闭TD条件只有模仿更新，不算RL。

|条件|2025四港验证Score|相对参考均值差|五种子配对95%区间|
|---|---:|---:|---|
|参考TD价值学习+模仿|-0.745752|0|0—0|
|只关闭TD，保留模仿|-0.653560|+0.092192|+0.050670—+0.163731|
|只关闭模仿约束|-0.799522|-0.053770|-0.108950—+0.018922|
|只将gamma改为1|-0.714704|+0.031048|+0.002042—+0.086890|
|只冻结共享特征层|-0.694420|+0.051332|+0.006958—+0.126515|
|只用已发生回报替代自举目标|-0.691257|+0.054495|+0.014485—+0.122851|
|只将学习率降至十分之一|-0.693082|+0.052670|+0.009147—+0.123178|

通俗解释：原策略已经模仿了MPC，但随后用自己估计的未来价值继续修改网络，决策反而变差。关掉这一更新明显改善；固定共享特征、减小更新或不用自举也有改善。这支持当前**价值学习过程破坏模仿策略**的诊断。

结论限于本次固定回放干预；它不是上一轮在线探索轨迹的逐步复刻。不能把改善相加，不能给每个机制随意分配因果占比，也不能把“只模仿”包装成RL胜出。MC目标来自固定行为的回报，不是无偏的最优Q标签。五个种子只是计算重复，不是五次独立港口现场试验。

原始动机参考[Double Q-learning原论文](https://arxiv.org/abs/1509.06461)，论文不替本项目证明具体退化原因。

证据：`.runtime/learning-v3-20261030/ablation-development.json`、固定回放NPZ、35份网络及全部验证曲线。研究代码和输出已封存，复查用只读核查脚本；不得覆盖旧目录重训。

## 经验模型RL、强MPC与独立新港

新增策略单列为**经验模型离线RL**：使用2019—2024四个训练港的8,280条训练期预测残差，估计转移不确定性；在声明的队列与成本物理先验上做离线随机Bellman备份。测试时只对封存策略表插值，不调用在线MPC，也不拿MPC回退动作充作RL。

这不是模型无关DQN，也不表示学到了真实岸桥或堆场物理。需求、波动、积压和剩余期均作离散近似；大积压超出表范围时取最大可行动作，作为明确的外推规则。所有实际流量、服务和原成本仍按相同代理环境计算。

噪声尺度0.5/1/1.5按2025四港验证选择。MPC同时比较7/14/28步、稳健系数0/0.5；验证分数同等时按封存的名称顺序选择MPC14。开发集经验模型RL为−0.651694，MPC为−0.655105。选型封存后才打开以下新港的2026年1月、4月90天窗口。

新港：**Santos、Le Havre、Yokohama、Kaohsiung、Salalah、Gioia Tauro、Auckland、Callao**。共22,096条真实逐日记录，实际2019-01-01至2026-07-24。来源为[IMF PortWatch官方Daily Ports Data](https://portwatch.imf.org/datasets/83b1bbc7b3354c5fb1f40673bb8f852e_0/about)。从此前固定的完整官方导出中新提取，未冒充新的下载版本或供应商。身份与国家地区名称按来源保留。

四港训练/2025选型；新八港完全不拟合、不选型，但允许各港以前已可用的历史作滞后上下文。公共发布延迟7/14天、容量归一化、队列和故障仍为显式假设，非现场生产数据。

新留出结果：经验模型RL Score **−4.040289**，验证选定MPC **−4.152532**，平均代理成本低**2.7030%**。三种压力的平均Score差均为正。但常态优势主要来自Salalah；港口簇95%区间为**[−0.002037, +0.336770]**，Santos、Yokohama、Auckland、Callao平均退化，最差港口差值−0.006200；可行压力窗口仍有4步违规。**研究准入仍为false。**

更稳健MPC在新留出也有更好表现，所有候选保留；不得事后更换验证选定基线来美化或隐藏比较。新的模型无关神经策略泛化仍差，原始TD和纯模仿对照也全部保留。

共26个具体策略实例×16个窗口×4情景，**1,664次运行、149,760帧**。完整证据：`.runtime/modelbased-v3-20261030/`。此前12港和已经看过的2026时期都按历史/开发证据保留，不再称为未看过的留出。

## 业务、协同、安全与Docker

新八港×常态/岸桥故障/电池故障/需求上冲，共32个工程案例。只用决策日2026-02-02之前7天的公开指标生成合成工单。全工单原子预留，资源时隙与可靠供电同时检查；这批案例原方法15个有未供电量，联合约束后为0。饱和负载测试另确认未能完整安排的工单整体暂缓、数量守恒且无半成品预留；暂缓不是完成。设备能力、200kW基础负荷、1000kW/岸桥、3000kW可靠电网、电池及新能源仍为工程假设，未变成实测标定。

冻结[DCSA PC2.0.0目的与范围](https://reference.dcsa.org/content/standards/releases/port-call/v2/pc-v2-purpose-and-scope)及[官方OpenAPI](https://reference.dcsa.org/content/standards/releases/port-call/v2/pc-v2-openapi-specification)，检查使用到的schema子集和E-R-P-A语义。已要求计划确认最新请求及相同时间、实际事件不得描述未来执行，验证时区、角色、UUID、幂等、冲突、时钟和分区；重做实际独立进程提交后崩溃及恢复重放。**没有完成官方外部一致性测试或MSW接入签收**，不能从规范文本推导机构授权。

Homebrew在当前Intel/macOS环境缺可用依赖瓶装包，失败日志保留；改用自有Lima Linux虚拟机，安装Ubuntu提供的Docker、Buildx和Compose进行实际构建。默认Dockerfile增加研究依赖锁，构建上下文排除主机`.env`、SQLite、LoRA及大模型权重、虚拟机和工具缓存。镜像包含CPU研究运行依赖和封存研究资料，**不证明容器内4B模型推理已验收**。

容器以非root、只读根文件系统、丢弃全部capabilities、禁止新增权限运行，使用自有持久卷。验证健康/就绪、研究API、260项源码/配置指纹、重启后卷标记保留及生产权限关闭。最终镜像ID、版本、日志哈希及完整回执见`.codex_artifacts/remediation-v3-20261030/container-acceptance.json`。

最终全仓751项Python、47项Node通过，Ruff0错误、compileall、pip check及release_check通过；八个实际本机适配器重新执行并恢复配置。独立核查重建1,664次运行、149,760帧，检查35份网络哈希及2,700次完整轨迹神经决策；重建28,726个物理预测及因果区间。输入/服务/成本/流量差为0，最大水位差约4.44e−16m、区间半径差约2.46e−16m。本地SHA链是完整性证据，不是外部签名或现场资格。
