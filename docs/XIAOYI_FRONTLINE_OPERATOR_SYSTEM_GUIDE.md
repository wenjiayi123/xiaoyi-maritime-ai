# 港航小懿AI一线操作人员系统指南

> Xiaoyi Maritime AI — Frontline Operator System Guide
> 适用版本：`port-ops.v1` / 运营沙箱与生产只读适配模式
> 指南版本：V1.0（2026-07-12）
> 使用原则：中文为主，英文标签仅作辅助；先核对象、再看时间、后看来源，涉及生产动作必须人工确认。

---

## 1. 指南目的

本指南面向港口调度员、值班长、设备主管、闸口班组、堆场人员、能源管理人员、单证人员和交接班人员，帮助一线岗位熟练使用港航小懿AI完成以下工作：

- 查看港区运营、船舶、设备、堆场、闸口、能耗和告警态势；
- 用现场口语向小懿提问，并补齐船舶、设备、泊位和时间等业务对象；
- 查询港航知识、SOP、法规、标准及其来源；
- 将复杂问题转成可暂停、可确认、可审计的智能任务；
- 生成运营、能耗、告警和管理报告；
- 整理班前重点、当班处置清单和交班摘要；
- 明确运营沙箱、生产数据、知识证据和生产控制之间的边界。

小懿是辅助分析和知识决策工具，不代替船长、调度员、值班负责人、设备主管、安全主管、海事、海关或其他法定责任岗位。

## 2. 必须先理解的三类信息

### 2.1 运营沙箱数据 / Operations Sandbox Data

页面显示 `运营沙箱`、`动态沙箱` 或 `SANDBOX` 时，数据由小懿后端按真实港口业务结构动态合成，用于培训、流程验证和应聘展示。它不是现场生产实绩，也不能作为设备控制或正式调度依据。

它具有：

- 船舶、泊位、岸桥、AGV、堆场、闸口等业务对象；
- 观测时间、生成时间、来源系统和质量码；
- 随时间变化的运营指标和告警；
- 与生产适配器一致的 `port-ops.v1` 数据契约。

它不代表：

- 某个真实港口的现场实绩；
- 真实设备状态或真实船期；
- 已获授权的控制指令；
- 可直接用于生产调度、对外申报或事故结论的数据。

### 2.2 生产实绩 / Verified Live Data

只有同时满足以下条件，页面才可将数据标记为生产实绩：

1. 数据模式为 `live`；
2. 数据源返回 `live_data_verified=true`；
3. 契约版本为 `port-ops.v1`；
4. 来源系统、观测时间、质量码和延迟可见；
5. 站点数据适配器和业务责任人已完成核验。

即使读取了生产实绩，小懿仍默认只读。生产写操作必须另行通过权限、连接器门禁和当前步骤人工确认。

### 2.3 知识证据 / Knowledge Evidence

知识问答依据本地RAG索引。当前运行快照包含：

- 112份已登记知识文档；
- 708个检索片段；
- 60份经发布机构页面核验的来源资料（摘要、目录或指南，不等于全文）；
- 52份项目内部整理资料。

数量会随知识库更新而变化，操作员应以页面和“系统状态”中的实时统计为准。

官方来源摘要只说明资料来源、版本、公开事实和适用边界，不等于系统已经取得所有法规、公约或标准全文。涉及强制条款、具体限值、处罚、申报和高风险作业时，必须打开“依据与来源”并复核当前有效的正式文本和现场制度。

## 3. 系统启动与打开

### 3.1 管理或技术人员启动

在Mac终端执行：

```bash
cd <xiaoyi-ai-repository>
bash run.sh
```

看到以下信息表示服务已启动：

```text
Application startup complete.
Uvicorn running on http://127.0.0.1:8010
```

### 3.2 一线人员打开

使用浏览器访问：

```text
http://127.0.0.1:8010
```

不要只输入 `127.0.0.1`。如果打开错误端口，可能进入其他系统或旧服务。

### 3.3 页面打不开时

按顺序检查：

1. 启动终端是否仍在运行；
2. 地址是否为 `http://127.0.0.1:8010`；
3. 终端是否出现 `address already in use`；
4. 是否重复运行了多个 `bash run.sh`；
5. 刷新浏览器，必要时关闭旧页面后重新打开。

若端口被占用，不要连续重复启动。通知管理员确认8010端口上的旧进程，再决定复用或关闭。

## 4. 页面布局总览

### 4.1 顶部主菜单 / Main Navigation

顶部菜单按实际顺序为：

1. **智能对话 / AI Dialogue**：提问、追问、查看证据和生成后续行动；
2. **决策建议 / Decision Advisory**：查看风险焦点和候选处置方案；
3. **数据分析 / Data Analytics**：查看运营、能耗、碳排和设备趋势；
4. **知识库 / Knowledge Base**：搜索文档、目录、来源和知识全景；
5. **任务中心 / Action Center**：创建并推进可审计智能任务。

### 4.2 左侧功能栏 / Side Menu

左侧依次包括：

- **新建对话 / New Dialogue**：清空当前工作区，开始新的业务问题；
- **对话历史 / Dialogue History**：恢复本机浏览器保存的最近对话；
- **常用指令 / Quick Commands**：打开一线岗位快捷问法；
- **我的收藏 / Favorites**：查看收藏的问题、回答和证据；
- **接口中心 / Connector Center**：查看TOS、PCS、EMS、EAM、VTS等接入状态；
- **智能联动中心 / Intelligence Hub**：查看七项能力和跨系统隔离预览；
- **RAG评测闭环 / RAG Evaluation Loop**：运行固定问答评测并提交纠错反馈；
- **推荐指令 / Recommended Prompts**：直接发起班次、船舶、设备、交班和SOP问题；
- **深海模式 / Deep Sea Mode**：切换界面视觉主题；
- **真实RL训练实验室 / Reproducible RL Lab**：使用真实公开能源时序或站点CSV，运行四种强化学习算法与PID控制基线；训练阶段不渲染，训练完成后才使用保留测试集生成轨迹。默认公开数据不是港口实绩。

### 4.3 右侧运营栏 / Operations Rail

右侧包括：

- **实时运营概况 / Live Operations Overview**；
- **能耗实时指标 / Live Energy Metrics**；
- **预警与提醒 / Alerts & Notifications**；
- **知识库快捷分类 / Knowledge Quick Tags**。

窄屏或小窗口下，左右栏可能收起。使用顶部的侧栏按钮和图表按钮重新打开。

### 4.4 顶部状态工具

- 点击时间区域：打开“系统状态”；
- 点击铃铛：查看当前活动告警；
- 点击齿轮：调整主题、默认回答模式和证据数量；
- 点击管理员头像：查看当前角色、知识索引和生产安全边界。

## 5. 每班开始前的标准检查

每次接班或开始培训前，建议完成以下六步。

### 第一步：确认系统状态

点击顶部时间区域，检查：

- 小懿回答引擎是否“就绪”；
- 港航知识索引是否“可检索”；
- 文档数、片段数和官方来源数是否正常；
- 生产连接器是否“真实在线”或“待配置”；
- 运营看板的数据模式是否明确。

### 第二步：确认数据来源

点击回答区的“运营沙箱/生产数据”标签，检查：

- 当前适配器；
- `schema_version`；
- 来源系统和港区代码；
- 观测时间；
- 延迟；
- 质量码和质量分；
- `live_data_verified`；
- 真实性声明。

如果标签是 `SANDBOX`，不得将数值作为现场实绩汇报。

### 第三步：查看活动告警

点击铃铛或“预警与提醒—查看更多”，记录：

- 告警对象；
- 告警等级；
- 发生时间；
- 来源系统；
- 当前状态；
- 推荐核对动作。

### 第四步：检查上一班未闭环任务

进入“任务中心”，查看：

- 执行中任务；
- 当前步骤；
- 是否等待人工确认；
- 已完成结果；
- 最近更新时间。

### 第五步：生成班次优先级

在推荐指令中点击“本班先处理什么”，或输入：

```text
根据工作台当前活动告警，按人员安全、生产影响和时间窗口排出本班前三项。
```

### 第六步：形成班前确认

值班长应确认：

- 当前数据模式；
- 三项最高优先事项；
- 每项责任岗位；
- 下一检查时间；
- 哪些动作必须现场复核或人工确认。

## 6. 智能对话的正确使用方法

### 6.1 基本提问

在底部输入框填写问题，点击发送按钮或按Enter。使用 `Shift + Enter` 可换行。

提问时尽量包含五类信息：

```text
业务对象 + 当前状态/问题 + 时间范围 + 目标 + 输出形式
```

示例：

```text
工作台里QC-03最近30分钟单位作业能耗偏高，请按先安全、后诊断、再恢复给出处置步骤，并标明需要谁确认。
```

### 6.2 现场口语可以直接说

小懿支持一线常用口语，例如：

- “这船咋还没靠？”
- “3号桥吊怎么了？”
- “这个班先干啥？”
- “南闸口要不要增开？”
- “帮我整理一下交班。”

当业务对象不明确时，小懿会追问船名、IMO编号、泊位、设备号或时间范围。请先补齐对象，不要要求小懿猜测。

### 6.3 四种回答模式

点击输入框右侧“专业”按钮可选择：

| 模式 | English | 适用场景 |
| --- | --- | --- |
| 专业问答 | Expert Q&A | 概念、标准、制度、系统职责和原因分析 |
| 运营问答 | Operations Q&A | 班次、船舶、泊位、堆场、闸口和设备研判 |
| SOP生成 | SOP Generation | 告警、故障、事故、危险品和应急处置步骤 |
| 简报摘要 | Executive Brief | 交班、日报、管理摘要和客户沟通要点 |

### 6.4 严格证据开关

默认开启“严格证据 / Strict Evidence”。建议一线人员保持开启。

开启后：

- 专业事实必须命中已登记索引；
- 法规、标准和监管问题优先要求官方来源；
- 证据不足时明确拒答；
- 不会用未验证内容补齐专业结论。

关闭后仍会显示来源，但专业事实的强制拒答门槛会降低。安全、法规、危险品和生产操作问题不得为追求“有答案”而关闭严格证据。

### 6.5 智能操作开关

输入框左侧“智能操作 / Agentic Mode”开启时，小懿会先判断问题是否可以转成白名单界面操作计划。

- 普通知识问题：继续进入RAG问答；
- 可执行界面指令：生成逐步计划并显示执行轨迹；
- 高风险动作：在确认步骤暂停；
- 未登记动作：不执行；
- 生产写操作：不会因智能操作开启而自动获得权限。

如只想提问、不希望自动切换页面，可临时关闭智能操作。

### 6.6 如何看懂回答可信度

每次回答重点查看：

- **证据覆盖度 / Evidence Coverage**：问题关键内容被索引证据覆盖的比例；
- **来源质量 / Source Quality**：官方来源、内部整理、混合来源或运营沙箱事件流；
- **置信度 / Confidence**：高、中、低；
- **依据与来源 / Evidence & Sources**：来源机构、URL、版本、摘要和哈希；
- **拒答原因 / Refusal Reason**：证据不足、需要官方来源、需要生产数据或业务对象缺失。

置信度高不等于已取得执行授权。证据覆盖度100%也不等于现场条件已经满足。

### 6.7 五类典型追问

获得首个回答后，可以继续问：

1. “这个结论依据哪份文件？”
2. “适用于哪个港口、设备和时间范围？”
3. “还缺哪些现场数据才能确认？”
4. “按先安全后恢复列成操作清单。”
5. “把结果整理成交班摘要并标明责任岗位。”

## 7. 运营态势和数据分析

### 7.1 实时运营概况

右侧运营概况通常显示：

- 当前在港船舶；
- 今日累计吞吐量；
- 岸桥作业利用率；
- AGV在线率。

这些是汇总指标。判断具体船舶或设备时，必须继续核对业务对象、原系统记录和观测时间。

### 7.2 能耗趋势

“能耗实时指标”和“数据分析”页面支持：

- 今日；
- 7日；
- 30日。

图表展示能耗、碳排和对比基线。鼠标悬停或键盘聚焦数据点可查看时间和值。

研判顺序建议为：

1. 看数据时间和模式；
2. 看总量变化；
3. 看单位吞吐强度；
4. 看岸电利用率；
5. 定位峰值时段；
6. 结合船舶作业量、岸桥工况和冷藏箱负荷复核；
7. 再生成调度或节能建议。

不要只凭总能耗上升判断“能效变差”。作业量、船型、设备组合、气象和统计口径都可能影响结果。

### 7.3 数据异常时

如果指标为空、时间过旧或来源不明：

- 不抄录数值；
- 打开数据来源弹窗；
- 检查系统状态和连接器；
- 在回答中明确“数据不可用”；
- 转人工或原系统复核。

系统接口失效时，页面不会回退为固定假数据冒充现场实绩。

## 8. 决策建议

进入“决策建议 / Decision Advisory”后，可查看：

- 今日决策焦点；
- 风险态势；
- 建议执行链；
- 生成智能方案。

建议执行链遵循：

```text
识别目标 → 评估约束 → 生成候选方案 → 人工确认
```

以泊位冲突为例，提问应包含：

- 船名或IMO编号；
- ETA、ETB、ETD；
- 计划泊位；
- 前船剩余作业量；
- 岸桥、拖轮和引航窗口；
- 吃水、潮汐或航道限制；
- 希望优化的目标。

小懿输出的是候选建议，不是已发布的泊位计划。最终计划由有权调度人员确认并在正式TOS/PCS中发布。

## 9. 预警与异常处置

### 9.1 查看预警

点击铃铛或右侧“查看更多”，预警详情包括：

- 标题；
- 等级；
- 消息；
- 来源；
- 发生时间；
- 推荐动作；
- “让小懿生成处置步骤”。

### 9.2 处置总原则

所有异常建议遵循：

```text
先保人身与设备安全 → 再核对象和来源 → 控制影响范围 → 诊断原因 → 授权恢复 → 留存记录
```

### 9.3 QC-03岸桥能耗告警示例

推荐提问：

```text
工作台里QC-03当前告警是什么？按先安全、后诊断、再恢复给处置步骤。
```

操作员应核对：

- 设备号是否为QC-03；
- 最近30分钟作业量；
- 待机时间；
- 起升和小车机构工况；
- EMS计量点；
- EAM故障码；
- 是否需要转检修工单；
- 设备主管是否确认停机或恢复。

### 9.4 船舶未靠泊示例

不推荐：

```text
这船怎么还没靠？
```

推荐：

```text
工作台里EASTERN HORIZON当前为什么还没靠？请按引航、前船剩余作业量、拖轮、航道窗口和船方ready状态列出核对顺序。
```

### 9.5 闸口波峰示例

推荐提问：

```text
工作台里南闸口当前排队情况怎样？是否需要增开备用车道？先列出必须核对的条件。
```

不能只看当前排队车辆数，还应核对：

- 未来30分钟预约到车；
- 开放车道；
- 单车处理时间；
- 场内接纳能力；
- 备用车道人员；
- 场外道路情况。

### 9.6 危险品、火灾、泄漏和人员伤害

这类问题必须优先执行现场报警、停工、疏散、隔离和应急预案，不得先等待AI回答。

小懿可用于：

- 整理已采取措施；
- 检索对应SOP和官方来源；
- 生成核对清单；
- 提醒升级岗位；
- 形成事件记录和交班信息。

小懿不得代替应急指挥、消防、医疗救援或危险品专业人员。

## 10. 知识库使用

### 10.1 搜索

进入“知识库 / Knowledge Base”，在搜索框输入至少两个字符。可搜索：

- 港口运营；
- 船期和靠离泊；
- TOS、PCS、EDI；
- 集装箱、VGM、闸口和堆场；
- 岸电、能耗和碳排；
- 设备维护与告警；
- 危险品、安全和应急；
- 海事、海关和法规；
- IMO、DCSA、IHO、IALA、WCO等标准资料。

### 10.2 专业目录

点击“专业目录 / Professional Catalog”，可按：

- 已索引；
- 部分覆盖；
- 计划采集；
- 关键词；

筛选24个专业大类和96个主题。

“已索引”只表示本地可以检索，不代表内容完整或当前适用于所有港口。

### 10.3 来源审计

点击“来源审计 / Source Audit”，重点检查：

- 发布机构；
- 来源URL；
- 版本；
- 官方或内部整理；
- 验证状态；
- 文档SHA-256；
- 片段数量。

### 10.4 依据与来源

在智能回答中点击“依据与来源”，应优先核对：

1. 来源是否匹配当前问题；
2. 是否为官方发布来源；
3. 版本和核验日期是否满足业务要求；
4. 内容是全文、摘要还是内部整理；
5. 是否需要现场制度补充；
6. 是否存在多条来源冲突。

### 10.5 上传资料

点击输入框左侧回形针，可提交：

- TXT；
- Markdown；
- CSV。

限制：

- 单文件不超过2MB；
- 文本不超过1,000,000字符；
- 当前不直接解析PDF、Word和Excel；
- 上传内容只进入待审核隔离区；
- 填写官方URL或勾选“官方来源”不会自动完成核验；
- 未经人工审核、登记和重建索引，不会进入正式问答。

不要上传账号密码、生产密钥、个人敏感信息、未授权商业资料或受限标准全文。

## 11. 任务中心

### 11.1 当前任务模板

任务中心包含：

1. 分析今日港口能耗；
2. 生成泊位调度候选建议；
3. 辅助处置运营预警；
4. 生成港口运营日报。

### 11.2 创建任务

点击模板后，小懿会创建运营沙箱任务并打开执行抽屉。抽屉显示：

- 任务标题；
- 数据边界；
- 当前进度；
- 当前步骤；
- 每步结果；
- 是否需要人工确认。

### 11.3 推进方式

- **执行下一步**：逐步推进，适合培训和复核；
- **自动执行**：自动推进低风险步骤；
- **暂停**：关闭抽屉或停止自动推进；
- **人工确认后继续**：高风险任务最后一步必须由授权岗位确认。

### 11.4 人工确认意味着什么

在运营沙箱中，确认只会推进沙箱任务并记录审计轨迹，不会控制真实设备。

在未来生产接入中，人工确认仍不等于必然下发。系统还必须同时满足：

- 连接器真实在线；
- 当前用户权限正确；
- 写操作已在服务端启用；
- 对象、参数和影响范围明确；
- 当前动作获得单次确认；
- 生产系统接受并返回可审计回执。

### 11.5 任务结果

完成后可以：

- 查看每一步结果；
- 回看审计轨迹；
- 生成报告；
- 将结果整理为交班或管理摘要。

交班摘要至少应包括：

- 总占用率；

### 13.5 告警与未闭环事项

- 告警对象和等级；
- 首次发生和最后更新时间；
- 已采取措施；

- 责任岗位；

- 需要升级或确认的动作。

“已执行动作”不等于“事项已闭环”。只有风险解除、结果验证、责任人确认和记录完整后才能标记闭环。

## 14. 接口中心

接口中心用于查看：

- 接口类型；
- 真实在线数量；
- 契约测试数量；
- 待配置数量；
- 读取和写入能力；
- 字段映射；
- 认证方式；
- 写操作门禁；
- 健康检查结果。

状态解释：

| 状态 | 含义 |
| --- | --- |
| 待接入 / Offline | 未配置站点地址或凭据 |
| 契约测试 / Contract Test | 只验证接口形状，不代表生产在线 |
| 配置异常 / Misconfigured | 已选择生产模式但配置不完整或不合法 |
| 真实在线 / Live | 真实HTTP健康探测成功且状态已验证 |

不要把“接口类型已装配”理解为“生产系统已在线”。

## 16. RAG评测与反馈闭环

点击左侧“RAG评测闭环”，可查看：

- Hit@K；
- 官方来源要求通过率；
- 知识文档和片段数量；
- 持久审计数量。

发现回答有问题时：

1. 选择1至5分；
2. 填写具体修订建议；
3. 点击“提交待审核”；
4. 等待人工审核。

高质量反馈应包含：

- 原问题；
- 错误点；
- 正确业务对象；
- 适用范围；
- 正确来源或现场制度；
- 建议回答。

反馈不会直接修改正式知识库。它只进入人工审核队列，避免错误反馈污染RAG索引。

## 18. 常见状态和处理方法

| 页面提示 | 含义 | 操作员处理 |
| --- | --- | --- |
| 沙箱态势·已追溯 | 使用动态合成事件并保留来源信息 | 可用于培训和流程验证，不作为生产实绩 |
| 官方来源N条 | 命中已登记官方摘要 | 打开来源，核对版本和适用范围 |
| 已索引证据N条 | 命中内部或一般索引资料 | 可用于业务解释，高风险结论需进一步复核 |
| 实时数据待接入 | 当前问题需要生产数据 | 转TOS、PCS、EMS、EAM、VTS等原系统核对 |
| 证据不足·已拒答 | 当前索引覆盖不足 | 补充对象、标准名称、时间范围或正式资料 |
| 业务对象不明确 | 船舶、设备、泊位或时间缺失 | 提供稳定标识后重新提问 |
| 自动执行已暂停 | 已到人工确认步骤 | 由有权岗位复核后决定确认或取消 |
| 接口离线 | 后端或数据源不可用 | 不使用旧值，通知管理员并转原系统 |

## 19. 一线人员禁止事项

- 不把 `SANDBOX` 数值当作真实港口实绩；
