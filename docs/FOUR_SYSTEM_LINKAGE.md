# 小懿四系统联动中心

小懿的“四系统联动”不是四个静态网页链接。统一网关会先按本机端口契约校验服务身份，再启动缺失组件，并为每次真实联动生成 trace ID、耗时、输入摘要和 SHA-256 回执。最近一轮会把统一关联 ID、完成数、失败目标和单系统回执写入 SQLite 运行态存储，服务重启后仍可恢复；失败也会固化到对应系统卡片并提供单系统重试，不会在提示消失后伪装成“尚未执行”。

启动就绪采用轻量服务健康接口；训练、仿真、审计等深度联动状态由能力调用单独读取。两者分离，避免重型状态聚合超时导致“服务已在线但仍显示启动中”。

## 联动对象

| 系统 | 实际联动 |
| --- | --- |
| 港口数字孪生 | 调用登记的助手动作和 RL 集成健康接口，返回匹配动作、集成就绪度及在线系统数 |
| 能碳驾驶舱 | 调用离线优化重算接口，返回数据集、减排与成本结果；生产写入保持关闭 |
| 马六甲沙盘推演 | 读取 RL 健康状态和公开数据快照，返回算法、数据来源和受监测船舶规模 |
| 航行模拟器 | 只读取登记进程的隔离状态；不自动启动、不注入航线或控制指令，也不修改桥接文件 |

## 使用方式

需要调节参数、持续观测和恢复配置时，使用“参数调整与观测”进入新增[联动智能体操作台](LINKED_AGENT_OPERATIONS.md)。其 8 项动作通过目标业务接口执行；能碳和数字孪生是本次计算参数，马六甲情景和时钟会实际改变本机沙盘配置。此入口对航行模拟器仅核验隔离状态。

1. 运行 `XIAOYI_LOCAL_MODEL_PROFILE=lora bash run.sh`。
2. 打开 <http://127.0.0.1:8010/>。
3. 点击左侧“四系统联动”。
4. 使用单系统“执行联动”，或点击“一键联动演示”。
5. 航行模拟器只有在用户主动选择启动入口时才打开；执行联动与状态刷新只核验隔离状态。

## API

```text
GET  /api/system-linkage/overview
POST /api/system-linkage/start
POST /api/system-linkage/command
```

`/api/system-linkage/command` 只访问登记的本机接口，并读取航行模拟器状态；网关拒绝外部主机与接口重定向。当前联动用于离线数据、仿真和策略预演，不代表已接入上海港生产系统，不下发真实设备或船舶控制指令。

端口分配、服务身份与冲突处理见 [本机系统启动指令](SYSTEM_LAUNCH_COMMANDS.md)。
