# 联动智能体操作台：参数、观测与配置恢复

2026-09-07 新增。小懿现在可以将明确的自然语言请求转成登记任务，读取目标配置，执行参数试算或本机模拟调整，连续观测并回填结果。任务由后端执行，关闭面板不会伪造完成或终止服务器任务；可从操作历史重新读取、停止或导出回执。

## 已接入的实际能力

| 目标系统 | 新增动作 | 参数和执行范围 |
| --- | --- | --- |
| 能碳驾驶舱 | 运行状态观测、参数对比试算 | 基准与候选绿色偏好 0～1、试算碳价 0～5000 元/吨；调用目标优化重算接口，两次结果必须使用同一数据集及哈希。参数仅作用于本次离线计算，不改变驾驶舱全局配置。 |
| 港口数字孪生 | 运行状态观测、情景评估 | 8 种登记情景、评估窗口 15～360 分钟、步长 1～60 分钟；调用运行态和序列接口，返回实际模型输出。不是修改当前全局策略。 |
| 马六甲沙盘 | 运行状态观测、情景调整、时钟运行或暂停 | 8 种情景：正常运行、集中到港、航道关闭、设备故障、恶劣天气、航道拥堵、堆场饱和、数据失联。实际写入目标沙盘配置，再回读核验。 |
| 航行模拟器 | 隔离状态核验 | 仅读取登记进程状态，此操作台不启动 Godot 或下发船舶运动指令。已有单次演示桥接保持独立。 |

观测支持 1～12 次采样，每次间隔 1～10 秒，显示趋势、之前与之后的指标和差值。运行状态观测包含模拟时间演进，不能单独用其差值证明调参收益。能碳试算与能碳实时模拟是两条数据链，页面单独展示。

## 使用方法

1. 使用原来的 `bash run.sh` 启动小懿，打开终端显示的本机地址，默认端口 8010。
2. 在左侧“四系统联动”中启动所需目标；检查其运行状态。
3. 点击“参数调整与观测”，选择动作与参数，点击“读取状态并预览方案”。
4. 检查目标、当前配置、本次参数和恢复选项，再点击开始。方案有效期为 5 分钟，修改参数后需要重新预览。
5. 查看最终结果、观测图表与差值。可停止后续观测、刷新历史回执、导出 JSON；取消不会中断已经发出的目标请求。

智能操作模式支持以下直接指令：

- `能碳绿色偏好调到 0.8，碳价 100，进行对比试算`
- `马六甲切换集中到港并观测`
- `暂停马六甲模拟时钟并观测`
- `观测数字孪生`
- `评估数字孪生高密靠泊，窗口60分钟`

明确的指令会生成实际执行步骤并把结果回填对话。马六甲写操作保留现有智能操作确认步骤；普通问题不会被当作操作。缺少参数、未登记的全局调整和多个目标混写会提示明确范围，可使用操作台填写完整参数。

## 执行和恢复规则

- 每份方案只接受一次执行；同一请求编号的重发返回原任务。每个目标同一时间只运行一个操作或恢复任务。
- 默认观测结束或主动停止后，恢复本轮变更前的模拟配置。取消勾选可保留目标配置，随后从回执点击“恢复本轮配置”。恢复不会撤销已演进的模拟时间、队列和业务记录。
- 执行前核验目标配置与预览一致；恢复前确认目标仍是本轮配置。其他用户或目标系统改变配置后停止恢复，避免覆盖后续操作。目标重启也视为配置冲突。
- 写请求超时显示“需要核查目标状态”，不会盲目重试或宣布成功。小懿重启后不会自动重放未完成的写操作。
- 回执包含参数、前后配置、观测值、来源时间、读取时间、原始业务返回的 SHA-256 和事件哈希链；保留原始失败记录。哈希链用于本地一致性检查，不等同外部签名或独立不可篡改存证。
- 使用既有身份与角色权限，操作需要 `operations.manage`；普通操作人员只能读取自己的记录，管理员可以审阅。目标启用认证时，通过 `.env.example` 中对应令牌变量配置目标签发的访问令牌。

当前实现适用于 `bash run.sh` 默认的本机单进程服务，目标互斥锁位于进程内。多进程或多机器部署前需要共享任务队列与分布式互斥。目标写接口没有原子版本比较，因此小懿的写前检查与写后回读不能消除另一客户端同时写入的全部竞态；本机实验期间应避免其他客户端同时改同一目标。
