# v0.3.0 · Evidence-governed control plane

## 中文

`v0.3.0` 将小懿整理为可复现、可审计、默认安全的港航智能控制平面：

- 112 份登记知识文档、708 个检索片段、来源登记、权威覆盖矩阵与严格证据拒答；
- 动态运营沙箱与只读 `port-ops.v1` 生产适配器，只有 `live_data_verified=true` 才能标记真实数据；
- JWT、四级 RBAC、请求限制、持久幂等、SQLite 状态、深度就绪、Prometheus 和 JSON 请求日志；
- 白名单智能操作、当前动作人工确认、持久任务/报告/审计与跨系统只读能力中枢；
- Q-learning、SARSA、Expected SARSA、Double Q-learning 和 PID 五基线真实实验；
- UCI CC BY 4.0 公开数据、时间顺序训练/验证/保留测试、无渲染训练、模型/配置/数据哈希；
- 锁定依赖、Ruff、206 项测试、前端语法检查、数据血缘门禁、容器干净构建和 GitHub Actions。

## English

`v0.3.0` organizes Xiaoyi as a reproducible, auditable, secure-by-default maritime intelligence control plane:

- 112 registered knowledge documents, 708 retrieval chunks, provenance registry, authority-coverage matrix, and strict evidence refusal;
- dynamic operations sandbox plus a read-only `port-ops.v1` adapter that requires `live_data_verified=true` before any live label;
- JWT, four-role RBAC, request limits, durable idempotency, SQLite state, deep readiness, Prometheus, and JSON request logs;
- allowlisted agentic workflows, action-scoped human confirmation, durable tasks/reports/audit, and a read-only capability hub;
- real Q-learning, SARSA, Expected SARSA, Double Q-learning, and PID baselines;
- UCI CC BY 4.0 public data, chronological train/validation/held-out test isolation, no-render training, and artifact hashes;
- locked dependencies, Ruff, 206 tests, frontend syntax checks, provenance gates, clean container builds, and GitHub Actions.

## Boundary · 边界

默认运营数据是动态合成沙箱；内置 RL 数据是公开建筑能源基准；知识库包含原创整理、公开摘要与来源目录。此版本不是经认证的无人值守船舶导航、港口控制或安全关键系统。

Default operations data is dynamically generated sandbox data. The bundled RL dataset is a public building-energy benchmark. The knowledge base contains project-authored material, public summaries, and source locators. This release is not a certified unattended vessel-navigation, port-control, or safety-critical system.
