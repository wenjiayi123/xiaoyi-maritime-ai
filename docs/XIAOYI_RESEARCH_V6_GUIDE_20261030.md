# 小懿V6实操、验证与结果解释（2026-10-30）

本轮提高的是可复现研究、强基线和完整年度评价能力。相同安全约束下，新八港RL相对强MPC改善0%，仍不准入；年度3/8、季度13/32、新晚期时段5/16通过，长期全季资格仍失败。工程验收与顶级港口全业务验收分开，最终结果见ACCEPTANCE.json。

## 按钮操作

1. 打开 `http://127.0.0.1:8010`，点击「小懿能力实证演示」。若服务未启动，在项目目录执行 `bash run.sh`。本地4B和检索模型启动约需数十秒。
2. 查看「本轮独立验证 · V6」摘要。先确认页面所列结果是当前源码和已登记证据；版本变化或缺失时先暂缓采信。八步旧演示、旧RL、七日和历史失败仍保留。
3. 点击「新八港RL、五次拟合与消融」，等到出现独立回执编号和完成状态。港口、窗口、压力、拟合种子各选一个，再点击「核对所选90天完整轨迹」。这会读取冻结的完整历史回放，不重新训练，也不把查看过的样本重新叫独立留出。
4. 先读逐港成本改善与失败，再看积压、过滤后动作、原始动作及安全干预。展开「为什么仍没有RL净收益」。不能只看平均分或看似好看的曲线。原策略看似改善7.5617%是与有过滤器的MPC比较，过滤条件不同，不是RL算法收益；有177次额外违规（五次拟合合计）。双方都无过滤器时，RL相对均值修正MPC反而约差0.7766%。这一补充比较是看过留出后的诊断，不能算新的独立准入证据。
5. 点击「完整年度与新时期孪生验证」。在下拉框选择 `Valparaiso · annual2025`，再点击「核对所选单元全部小时」；也查看其四个季度。全年8760个预期小时、冻结起点、观测、预测、强物理基线和原区间一并展示。横轴是真实UTC时间；真值缺失处断线，不插值、不压缩空缺。
6. 再选择 `Newlyn · annual2025` 和 `Kushimoto · annual2025`。前者历史不足/无返回而暂缓，后者区间覆盖未通过。参与评分点数与原始合格观测数分开：有真值但无合格冻结模型时，不能误称为观测也缺失。Lautoka和Wellington虽然全年均通过，各仍有季度失败，所以不能宣布全季合格。
7. 在对应结果下展开「对应原始公开来源、时间和下载（含失败响应）」。核对港口/站点、用途、时间、HTTP响应、官方查询和SHA256，点击下载。浏览器先算SHA256再保存。gz是原始响应正文的本地压缩文件，保留失败返回，不宣称是原始网络编码。MLLW和各站station zero不混成统一高程。
8. 点击「导出本次演示证据包」。包内含执行回执、失败请求、参数、来源、区间、算法范围和未演示步骤。导出动作不代表所有业务验收通过。展开「37项能力逐项改进、限制与实操入口」查看每项分数、五维依据和对应操作。
9. 需要实际4B调用时，使用「真实4B调用优化工具」；这是真实模型发起受约束工具调用，优化由HiGHS求解，正式报告由已核验工件汇总。它不等于开放式自主规划或外部科研同行评议。研究审阅的真实模型/规则回执另保存在本轮harness-review目录。

## 数字怎样读

| 数字/术语 | 通俗解释 | 不代表什么 |
|---|---|---|
| Score越高越好 | 队列、服务资源、切换、溢出和期末积压的负成本；同一合同内比较 | 真实收入、人民币节约、实测吞吐或生产率 |
| 相对成本改善0% | 同样安全过滤后RL与强MPC持平 | RL已经超过MPC |
| 95%港口簇区间 | 先在港内汇总窗口/种子，再按8个港口重采样 | 五次拟合就是40个独立港口或现场风险保证 |
| 五次拟合 | 训练数据按港口年度块重采样，得到5个冻结经验模型及策略表 | 5次独立现场实验，或神经网络梯度训练 |
| 838步违规/每次拟合 | 在全部64窗口的声明代理容量下，最大能力基线也出现同样838步；5次重复合计4190 | 真实港口不可避免违规；实港可增加设备/人员但这里没有该证据 |
| 可行窗口违规0 | 最大能力能零违规的窗口内，候选也未新增违规 | 所有时段都零违规 |
| 原始/过滤后动作 | 算法先建议，统一安全规则再提高能力档位 | 过滤器收益属于RL学习收益 |
| MAE | 平均每小时预测偏离真值多少米 | 最大误差或航行安全余量 |
| 区间覆盖 | 真值落在冻结区间中的比例 | 提前知道未来异常海平面或风暴 |
| 最大区间宽度 | 防止把区间无限放大以凑覆盖率；限0.75m | 可以看完测试后任意调宽 |
| 可用率 | 有足够真值和冻结模型可评分的点/所有预期小时 | 用邻站、月均或预测填补的“真值” |
| 回退强物理基线 | 复杂修正在历史滚动季度不能稳定更好时，实际采用简单模型 | AI额外精度提升 |

## 本轮数据、独立性和修正

RL使用40个已查看港口的2019–2024年训练、2025年选型；8个此前未使用港口的2026年1月和4月90天窗口，先冻结再提取测试。港口为Port Said、Jeddah、Dammam、Kobe、Chittagong、Karachi、Chennai和Dar Es Salaam，共22096行。它们来自同一份已固定的IMF官方全量导出，并非更新版本。官方HEAD仍显示2026-08-01的文件，数据止于2026-07-24；FeatureServer最新日期查询的上游错误也保留。

修正了14天发布延迟情景的容量代理标定时钟：只使用起始时已发布的最近28天，避免读到尚未公布的第一周。所有新比较共用修正后的合同，不能把跨版本、跨港成本差全部归因于RL学习。新增删失后验只在开发集研究；由于安全/成本取舍未稳定胜出，最终共享观测选择alpha=0，没有偷偷部署后验增强。

RL策略是经验模型驱动的离线Bellman控制，训练误差分布来自331200次已知历史情景交互，五次港口年度块自助拟合。不是神经DQN/MOPO复现。补充全部1至90剩余时域、尾部概率箱均值、长时域与随机MPC比较；需求均值网格0.4至3倍容量、积压0至12倍容量、8个波动分箱，超过均值或积压上界时选择最大允许档位，低于需求下界时裁剪。该域外处理不是MPC回退，但也不能算学习策略对网格外状态的泛化。阈值压缩、独立同分布误差、固定均值/波动及当前可用率持续等近似全部披露。原神经TD消融、旧集中收益和跨港失败仍保留。

孪生使用NOAA八站、UHSLC八站。新NOAA四站为Boston、San Diego、Apra Harbor和Portland；另四旧站用从未查看的2026-08-08至08-31和09-08至09-30时段。UHSLC新八站完整2025年，一次固定起点预测365天并检查四季；逐站历史是合法标定输入，不宣称“完全无站点历史的零样本预测”。2025年其他站点旧结果已经用于工程认识，因此不是整个2025世界从未被看过。

NOAA使用verified hourly_height、MLLW、GMT、米；UHSLC有限小时水位由毫米转米，质量>=3，保留3/4分布、record_id、垂直基准及last_rq_date。FD和RQ不混称实时现场数据。归档事件时间不证明这些最终修订值在预测起点已经公开，故仍是回顾性事件时间研究，不能升级为实盘资质。

## 为什么暂时不能把剩余六项宣布通过

- RL：安全版新八港无退化但只有持平；公平原策略诊断也未证明优于更强MPC。需要能带来新增决策信息或真实多资源耦合的状态/任务，再用新的留出验证，不能靠多训练或更换比较条件制造收益。
- 长期孪生：完整年度3/8、季度13/32、新晚期时段5/16。纯天文模型对非潮汐异常和跨年水位漂移缺少可提前获得的驱动，部分站点历史和测试覆盖不足；不能用测试水位回填。
- 短期同化：旧46/54和Fremantle真实缺测问题保留，本轮长期开环不替代短期资格。
- 全港物理：联合资源优化仍由真实宏观活动驱动合成工单；设备动态、水深、UKC等缺少同站实测标定。
- 跨机构协同：DCSA本地契约、乱序和恢复演练不等于官方沙箱和机构签收。
- 现场安全：缺少HIL、OT、长期影子运行、SLA和签字授权；公开归档能支持研究，无法补造这些现场证据。

对标依据采用当前MPA数字孪生方向：历史和实时数据、共享试验环境、跨机构协同、仿真与预测。37项分数是本项目证据成熟度量表，没有假设存在行业统一的“超级智能认证”。
