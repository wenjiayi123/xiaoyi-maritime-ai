# 小懿 AI 功能、速度、智能性与联动审视

审视日期：2026-09-07。范围：当前本地应用、实际 4B 生成服务、0.6B 向量检索、浏览器主要流程及三个业务系统的本地适配器。修改前工作树为 `3c28a040ba41309ddb65a40df2a821131d5ec5b2`。

结论：小懿已有较完整的港航知识、运营分析、任务、训练和证据治理模块，提升重点是问答路径的准确性、异常时的等待、跨轮上下文和联动回执的真实性。本轮已完成这些工程改进；没有重新训练或更换模型，也没有把离线演示升级为生产控制。

## 四个方面的结论与已完成改进

| 方面 | 发现的问题 | 本轮改进与验证 |
|---|---|---|

| 回答速度 | 官方入口已有完整索引仍调用生成；重复问题重复请求向量；向量服务失败可反复等待原 60 秒超时；状态探测串行累加 | 登记官方入口直接带引用回答；查询向量缓存 5 分钟、最多 128 条，同问题并发合并；交互向量超时默认 6 秒、失败冷却 30 秒后恢复；四个独立状态探测并行 |

缓存只保存查询向量，不缓存答案、设备状态、实时态势或执行结果。索引替换会更新检索句柄，分块内容哈希仍逐次核对。原有“生成及校验完成后统一显示答案”的交互保留。

另外修复了模型地址的本机判断：必须解析为精确的回环主机，伪装成 localhost 前缀的外部地址不能绕过外发授权判断。

## 实际回答时间

单位：秒，从本机 HTTP 请求发出到完整 JSON 回答收到，包含服务处理和本机传输，不包括前端完成文本的打字动画。相同电脑、相同模型，按同一组问题串行执行。每个阶段每题一次；这些是可复查的观察值，不能推导线上吞吐量或百分位服务指标。
