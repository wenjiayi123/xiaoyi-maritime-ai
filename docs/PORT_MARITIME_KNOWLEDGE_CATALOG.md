## 1. 目录边界

本目录是港航专业知识的**治理范围、采集路线图和覆盖盘点**，不是“已经收录所有港航资料”的声明。港航知识跨越不同国家和地区、不同港口、货种、船型、设备、厂商和监管体系，法规、标准、通告、费率、接口和现场制度也会持续更新，因此不存在一次性收齐且永久有效的静态资料全集。

当前覆盖状态是依据 `data/kb` 的文件名、标题和本地索引来源做的保守估算。当前快照包含 112 个 Markdown 来源、708 个索引片段；这只能证明内容在本地可检索，不能证明内容完整、现行有效或具有官方权威性。权威来源族的已覆盖、待补齐与许可隔离清单见 [`data/authority_coverage.json`](../data/authority_coverage.json)。

尤其是安全、危险品、通航、海事、海关、边检、环保、法律、技术标准和生产控制问题，必须使用适用辖区的现行官方文本、经批准的港口制度和真实接口数据复核。行业组织、厂商手册、教材、论文和内部整理资料可以辅助理解，但不能替代强制性官方依据。

## 2. 标记规则

### 2.1 优先级

- `P0`：安全、合规、核心生产或基础数据能力，优先采集、核验和维护。
- `P1`：关键业务和运营能力，在 P0 稳定后持续补齐。
- `P2`：延伸分析、市场、表达或辅助能力，按实际应用场景建设。

### 2.2 覆盖状态

- `indexed`：当前已有明确对应的知识文件且在本地索引中可检索；**不表示完整或官方**。
- `partial`：已有相关索引内容，但深度、范围、辖区、版本或来源权威性仍不足。
- `planned`：从当前文件名和标题盘点中未识别到专门资料，仍待采集和核验。

三级主题继承所属二级主题的优先级、覆盖状态和官方来源要求。目录中的“建议机构/资料族”表示应优先向这些来源采集，不表示相关材料已经入库。

## 7. “真正索引”的判定

一个主题只有同时满足以下条件，才可以从 `planned` 或 `partial` 提升为 `indexed`：

- 有可追溯的实际资料文件，而不是只在目录中写了标题；
- 文件已进入当前索引并能由目标问题稳定命中；
- 来源、版本、适用范围和有效状态有记录；
- 高风险主题至少包含官方来源，且回答能明确引用；
- 已有正向、反向、边界和无证据拒答测试；
- 索引片段没有把摘要、内部建议或模型生成内容冒充官方原文。

即使达到 `indexed`，也不能对外宣称“覆盖全部港航知识”或“数据百分之百真实”。对真实港口的实时状态、费率、船期、气象、监管状态和生产指令，仍然必须通过已授权接口取得并保留数据时间戳、来源和业务回执。
