## 修复与复现

### 任务读取失败后错误地显示全部完成

旧行为：任务推进先把当前步骤标记为完成，再读取数据。数据源异常后没有运行中步骤，下一次点击可能直接显示 100%，跳过剩余步骤。

现在先完成读取再修改任务状态。回归注入源读取失败，验证 API 返回 500、任务状态与进度不变；恢复数据源后同一步可重试，并依次完成全部步骤。

### 训练中心零参数被默认值替换

旧行为：合法的 `seed=0`、`discount_factor=0`、`epsilon_end=0` 被真值判断替换成默认值。

现在保留传入的零值。回归运行 10 回合 Q-learning 与 PID 对照，核验 API 配置、持久化 `run.json`、实际 `q_learning.json` 的种子和超参数；随后运行保留测试集并核对非生产边界。

### 验证阶段停止训练后又变为训练完成

旧行为：点击停止返回 `cancelling`，但正在执行的验证结束后完成回调会将状态覆盖为 `trained`。

现在完成回调在任务锁内再次检查取消信号。回归在实际训练后的验证入口暂停，发送停止请求，再恢复验证，核验最终为 `cancelled` 且测试接口返回 409。
