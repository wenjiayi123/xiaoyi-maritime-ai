# 旧高级 RL 展示接口退役说明

旧版“极端天气联合调度”和“岸桥—AGV—堆场多智能体协同”依赖其他本机项目
返回 MAPPO、MAS 和数字孪生结果。本仓库本身没有对应的环境实现、训练入口、
原始数据、模型检查点和模型哈希，无法让 GitHub 使用者独立复现。

因此这些入口已从页面移除，`/api/advanced-rl/*` 返回 HTTP `410 Gone`，不会再
根据动态公式拼装奖励、概率或策略赛马结果。

替代入口是 [`RL_AGV_ENERGY_MISSION_GUIDE.md`](RL_AGV_ENERGY_MISSION_GUIDE.md)
所述的 `/api/rl-lab`。它提供本仓库内可运行的真实训练、真实进度、模型产物、
时间顺序数据隔离和训练后测试渲染。

未来如恢复 MAPPO 或多智能体能力，至少必须同时提交：

- 环境状态、动作、终止条件与约束的可执行实现；
- 训练和评估数据的来源、许可、版本与哈希；
- MAPPO/MARL训练代码和固定依赖；
- 可重现随机种子与超参数；
- 模型检查点及其SHA-256；
- 独立测试集评估和安全约束测试；
- 训练不渲染、训练后才回放的前后端证据。

在这些条件满足前，不得把外部接口响应或视觉动画描述为本仓库已经完成的算法能力。
