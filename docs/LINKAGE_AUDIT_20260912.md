# 联动、能力中枢与接口中心专项验收

日期：2026-09-12。本报告覆盖小懿后端联动能力；全站浏览器按钮与画面由同期主审计验收。

## 修复

| 问题 | 修复后的行为 |
| --- | --- |
| 能力中枢的 urllib 与 FastAPI `Request` 同名覆盖，真实 GET 会返回 500 | 使用独立 HTTP 请求类型；实际目标数据可返回 |
| 能碳深度状态聚合偶发超过 3 秒，误报接口失效 | 此能力使用 15 秒有界等待；启动轻探针继续保持 1.2 秒 |
| 编排摘要把未完成能力统称为已完成，失败请求的证据状态不准确 | 显示完成与未完成数量；保留请求尝试事实，失败结果不升级为已核验实时证据 |
| 能碳、马六甲启动探针只要求任意 JSON 与 HTML，可能复用错误服务 | 核对登记服务名称、健康状态与前端标题，冲突时拒绝复用 |
| 四系统网关可能把缺少来源或业务不可用响应当成成功 | 检查业务对象、数据来源与隔离权限，保留失败回执；读取有大小上限，拒绝重定向并支持登记的目标令牌 |
| 文档仍描述航行模拟器的旧场景桥接 | 对齐当前隔离设计：联动只核验状态，显式启动入口独立 |
