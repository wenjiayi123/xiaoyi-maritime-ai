## 实际发现并修复的问题

保留的早期模型报告包含格式校验失败、本地语法转换不兼容、组合任务漏读和原生时间对象无法序列化。已分别加入轻量传输Schema与权威参数校验、必需工具与完成条件、可诊断的格式失败工件、与HTTP一致的快照编码。

额外审视修正了：最后允许的工具调用后仍可交付、审批已接受但尚未执行时被新约束撤销、追问/计划提交竞争、工件保留名覆盖、无变化的重复调用与有新证据的重复观测的区别，以及并行部分成功的合同计数。失败样本没有被删除或伪装为成功。

## 仍需明确的限制

1. 国际性能等级仍需同模型、同工具、同数据与预算的跨引擎实验，更多独立任务、重复试验与外部评分。
2. 通用自主多智能体、远程MCP客户端、主机代码执行和操作系统沙箱不属于当前已实现功能。
3. 原联动适配器的目标互斥仍以单进程为边界；目标没有原子版本比较或事务幂等时，不能承诺多机恰好执行一次。
4. 当前数据包含公开资料、离线计算与工程模拟；现场源、实船校准、设备联锁与生产调度需继续独立准入。
5. 原有自动测试全部通过，不等于每个外部系统此刻在线，也不等于原生桌面壳和所有按钮都已逐个手工复验。
