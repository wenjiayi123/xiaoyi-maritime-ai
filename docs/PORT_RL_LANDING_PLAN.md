# 港口 RL 落地执行清单

目标是让代码下载后保持完整证据链，只替换站点数据、字段映射和港口 profile
即可重新训练与评估；现场连接与权限仍需部署方配置。

| 阶段 | 交付物 | 当前状态 |
|---|---|---|
| 1. 代码与证据审计 | 4 RL + PID、训练/验证/测试、旧指标与模型清单 | 已完成 |
| 2. 公共数据扩容 | 19,735 行原基准、409,887 行大基准、NOAA 港口 AIS 场景 | 已完成 |
| 3. 港口环境语义 | 11 项观测、5 项动作、目标函数、安全掩码、国际港口因素 | 已完成 |
| 4. 可替换接入 | CSV 映射、`environment_type`、port profile 与哈希门禁 | 已完成 |
| 5. 多种子比较 | 三套数据、三个种子、五算法、保留测试与证据包 | 执行并固化报告 |
| 6. 同屏产品化 | 训练中心、算法矩阵、小懿训练顾问、全系统按钮联动 | 已实现，浏览器验收中 |
| 7. 发布门禁 | 测试、文档、截图、release-check、GitHub 更新 | 执行中 |
| 8. 站点联调 | DCSA/TOS/VTS/EMS/EAM、历史回放、影子模式 | 由目标港口提供接口后执行 |

## 站点仍需提供的内容

- 港口/码头身份、时区、坐标和业务日历；
- 只读历史数据及字段说明、单位、质量码和授权；
- DCSA Port Call、TOS、VTS/AIS、EMS、EAM、气象/潮汐映射；
- 泊位、岸桥、场桥、工班和作业能力的校准依据；
- 现场安全规则、动作白名单、人工确认岗位与回滚流程；
- 影子运行验收区间和港方认可的生产 KPI 定义。

仓库公共报告证明的是算法实现、数据规模、可复现性、时间隔离、约束和证据治理。
只有完成站点历史回放和影子运行后，才可以发布港口生产收益。
