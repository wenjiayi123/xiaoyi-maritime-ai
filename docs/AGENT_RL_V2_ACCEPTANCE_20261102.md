# 小懿 1.7B 语言模型 RL 第二轮验收

日期：2026-11-02。实验：`experiment-004`。本轮训练、模型选择、独立留出测试、能力检查、实际系统验收和记录重放均已完成。本文记录完成结果；展示包的最终文件完整性和页面检查另记在交付核验文件中。

## 可支持的结论

在本轮固定的任务环境、共同 Harness、13 个工具/参数候选和 24 个留出案例上，加入 RL 的模型完成 19 个任务，原冻结 SFT 完成 14 个，提升 20.8 个百分点。按案例配对，6 个任务由失败变成功，1 个由成功变失败。这是一次真实参数训练的有限范围正结果。

继续 SFT 的额外训练对照完成 22 个任务，规则完成 24 个。因此本轮不能证明 RL 优于继续监督训练、规则方法或所有 Harness，也不能证明任意任务的泛化。这里只运行了一个训练种子；“留出测试”表示与训练和选择分离，不表示第三方独立认证或统计显著性已经建立。

## 真实训练及留档

Qwen3-1.7B 的前部权重冻结，最后四层 q/v 投影使用 rank 8 LoRA，共 229,376 个可训练参数。D 与 E 从同一 C 检查点开始，使用相同的 512 个训练状态顺序、学习率、更新次数上限；D 用环境回报优化动作分布，E 用专家动作标签继续 SFT。

两组均完成 512 次更新，验证后均选择第 384 步。D 的全部 229,376 个 LoRA 数值相对 C 发生变化且有限，最大绝对变化为 0.0244298559。训练全过程保存每步输入、动作概率、回报、损失、KL、熵、梯度范数、耗时、权重摘要；每 32 步保存 LoRA、优化器和随机数状态，两组共 32 个中间检查点。保存状态不等于已经验证任意中断点的自动恢复程序。

实际方法为有限动作集上的两步模拟器前瞻 actor 优化，不是 PPO/GRPO，也不是自由生成工具 JSON 或任意数字。完整方法、目标函数和奖励定义见同目录 `AGENT_RL_V2_METHODS_20261102.md`。

原协议只验证 128、256、512 步；D 的 512 步在固定回归中退步到 7/8。最终测试打开前，已明确登记将两组都扩展为每 64 步选择，并保持相同门槛，未增加训练。原选择、修订时间、所有候选及不合格版本均保留，不将修订描述为最初预注册方案。

## 实际系统验收

三条指令、C/D 两组、每组每条一次、每次最多 18 步，均在最终测试打开前固定。全部六次由实验页面提交，模型逐步选择动作并调用原有本机 API，未用失败后的重试覆盖原结果。

| 指令 | D SFT＋RL | C 冻结 SFT |
|---|---|---|
| 读取港口、能碳、马六甲状态，能碳方案比较、港口情景评估、核验和联合报告 | 完成，8 步，恢复一次注入读取超时 | 完成，8 步，恢复一次注入读取超时 |
| 港口高密度靠泊情景评估并交付报告 | 未完成，18 步，重复核验未交付 | 未完成，18 步，重复核验未交付 |
| 能碳方案比较、读取超时恢复、核验和报告 | 完成，5 步 | 完成，5 步 |

用户要求的“至少一个实际指令完整闭环”已达到。两组此处同为 2/3，因此这六次执行不支持 RL 在原系统验收中超过 C 的结论；RL 相对 C 的正增益来自另行固定的 24 个合成留出测试。

RL 联合任务顺序：港口读取 → 能源读取（注入超时）→ 重试能源读取 → 马六甲读取 → 港口评估 → 能碳比较 → 结果核验 → 交付报告。能碳参数为基准偏好 0.50、候选偏好 0.82、碳价 85 元/吨。

RL 联合任务 ID：`arj-5fc6336f04654989ac3403de92a1afde`。RL 能碳任务 ID：`arj-9a5fc94a5e5d4cab9708dd569a0470f0`。全部任务位置记录在 `experiment-004/native-job-index.jsonl`。展示包的 `native/` 下保留六个任务全部输入、模型概率、原始 API 返回和已有报告。

系统数据属于公开数据和本机工程模拟。港口、能碳、马六甲各自的地点和模拟时钟分开记录，不能包装成同一真实港口同时刻联动；能碳比较出现成本下降但排放上升，报告如实呈现。下游港口策略身份声明与加载摘要不一致的警示保留，不能把业务计算结果当作已验证的下游 RL 增益。报告按核验事实自动排版，未验证自由撰写论文能力。
