# 小懿三层任务环境与RL优势验收方案

2026-11-02。用户要求持续监测、扩展训练，并以可向专家展示的真实RL优势为最终验收目标。本文件区分试跑、独立验证、原生系统验收。未达到标准，不标记验收通过；保留负结果后另建实验继续改进。

## 实验结构：三层环境 × 相同学习方法

| 层次 | 业务和变化 | 主要问题 |
| --- | --- | --- |
| 简单业务 | 港口查询、能碳比较、港口情景评估、交通查询、联合任务、读取恢复、回执恢复、时钟恢复，8类任务 | 基础能力如何；增加RL后是否遗忘或退化 |
| 复杂业务 | 三系统联合目标；超时、缓存过期、状态变更和回执丢失组合出现 | RL能否提高未见异常组合下的完整任务完成率 |
| 变化适应 | 同一联合业务；执行过程中工具菜单绑定更新、外部数据定时变化；接入新的目标接口合同 | 在环境变化后，RL能否以执行反馈更快恢复完成能力 |

每层均比较A规则参考、C共同SFT起点、D SFT＋在线RL、E继续SFT、F SFT＋RL经验复用。D/E/F每层从同一固定共同权重开始；各层分别重置权重，不把前一层某组的训练结果带入下一层。规则根据同样可见的状态和当前工具表执行，不故意弱化。

旧实验004的24项成绩作为独立的历史展示材料保留。它的任务、提示、训练起点与新实验不同，不能与新层次直接连线解释成同一条难度曲线。新简单层使用新实例，在同一新协议下与其他两层比较。

## 当前006与下一轮的衔接

006的配置和训练代码保持冻结，先完成D/E/F各24组。共同SFT为1/4；D在第8、16、24组均为2/4；E/F以实际后续记录为准。此处4是开发任务数，不是工具数或最终业务覆盖。

下一轮先做一次共享的源环境SFT：72个任务配置，共601个正确操作状态，512次单状态更新，来源为三个层次各24个源任务。固定使用旧004的E384作为父权重，不根据006中哪组成绩最好而更换。所有后续比较共用第512步权重。源环境开发检查为12项，至少完成3项才进入后续试跑；否则停止并保留失败，改进共同起点。

每层的任务池固定为：24个训练实例、8个开发实例、24个独立测试实例，另有16个旧工具能力实例。三个层次共72个训练实例、24个开发实例、72个独立测试实例。跨层旧能力题共享，不能重复计成48个独立旧能力任务。

试跑每层D/E/F各48次更新，固定打乱后的24个训练实例走两遍。D每次重新采样4条轨迹，即每层最多192条新尝试；F可能使用历史轨迹，新采样量单独记录；E复用D访问的状态并获得每个状态的正确动作标签，不能把D的成功率算作E的成功率。每条轨迹最多24步。下一轮各轨迹均从任务起点开始，不使用参考前缀。

开发节点为0、8、16、24、32、40、48。所有节点保留，展示时明确哪个是同预算节点，哪个是按开发规则选定的模型。试跑只判断可行性、训练成本与问题所在，不开启学习模型的最终测试。

## “面向未来”具体指什么

它是可复现的变化适应实验，而不是对未来港口的预测。工具的业务含义仍在13个已显示的工具/参数候选范围内，改变的是工具菜单绑定和数据更新时机。模型必须依据当前工具表选择操作，不能依赖旧字母对应的固定工具。

源SFT见过101—104号源合同；未来层适应601/602两个不同目标合同。适应训练、开发和最终测试共享目标合同，但任务数值、实例和事件时机分开。因此主问题是“接触新合同后能否通过训练适应”，不是“从未接触的新API能否零样本掌握”。未知工具的任意JSON生成、新设备现场控制和无限业务泛化不在本轮结论范围内。

时间扰动由独立于模型选择的预定步骤触发，未来事件时间和随机种子不进入模型提示。发生后只显示已发生的变化。每个合同对所有对照组相同。参考程序通过所有任务只证明环境可解，不属于模型实验。

## 最终验收目标（不是当前已经达成的结果）

正式确认阶段至少3个独立训练随机种子。先用开发集固定RL候选（D或F）、各组权重选择规则、预算和目标阈值，再一次性打开新的最终测试。试跑数据不进入正式优效结论。

提前登记两个主要优势指标，至少一项通过，并同时满足能力保持与原生闭环要求：

1. **复杂层完成率优势**：相同登记训练预算下，所选SFT＋RL在独立复杂任务上的平均完成率比继续SFT至少高10个百分点；同时提供按任务情景及训练种子分层/配对的不确定性分析，其差值区间下界须高于0。
2. **变化适应速度优势**：在固定适应节点上，所选SFT＋RL的归一化“适应过程完成率曲线面积”比继续SFT至少高0.10，差值区间下界高于0，且最终完成率至少80%。节点测试在所有训练与选型冻结后统一运行，不把中途最终测试分数反馈给训练。

两项主要比较使用Bonferroni校正：各报告97.5%双侧区间，控制两项任取其一带来的多重比较风险。模板重复不当作完全独立样本；每个种子、每类情景结果都公开。只有3个种子时区间可能很宽，未通过时如实保留。正式样本规模和统计实现须在正式训练前写入单独锁定协议，不能观察最终成绩后降低标准。

附加要求：旧工具能力平均完成率相对共同起点下降不超过5个百分点；报告失败及非法操作尝试；至少一条用户指令由最终语言模型在本机原生系统完整执行、核验、交付报告，无规则代选动作。规则接口探针不能充当模型验收。

其他指标包括错误恢复率、工具调用次数、重复操作、额外正确动作标签、训练时间、模型决策熵、KL、梯度和真实经验复用量。标注数量是资源指标，不能在未测工时的情况下宣称节省了多少人工费用。奖励增长不单独构成验收；工具安全门本身拒绝非法交付，也不能包装为RL独有安全收益。
