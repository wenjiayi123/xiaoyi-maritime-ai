# 小懿本机系统启动指令

在小懿输入框中使用以下指令。每条指令只映射到固定白名单目标，不接受任意路径或 Shell 命令。

| 输入指令 | 启动目标 | 启动与验证方式 |
| --- | --- | --- |
| `启动模拟器` | 桌面“航行模拟器” | 使用 `XIAOYI_SAILING_SIMULATOR_ROOT` 和 `XIAOYI_GODOT_BINARY` 登记项目与 Godot，核验主场景和进程 |
| `启动航行模拟器` | 桌面“航行模拟器” | 与“启动模拟器”相同 |
| `启动孪生` | `port-dt-multi` | “启动港口数字孪生”的录制用短指令 |
| `启动港口数字孪生` | `port-dt-multi` | 在专属 8000 端口启动网页数字孪生服务，同时校验首页和 `/health/live` 服务身份 |
| `启动能碳` | 能碳驾驶舱 | “启动能碳驾驶舱”的录制用短指令 |
| `启动能碳驾驶舱` | 能碳驾驶舱 | 启动前后端演示服务并检查 8808 业务接口，随后进入 5173 页面 |
| `启动沙盘` | 马六甲沙盘港口推演 | “启动马六甲推演”的录制用短指令 |
| `启动马六甲推演` | 马六甲沙盘港口推演 | 启动本机推演服务并检查 5174 的强化学习健康接口 |

三项联合优化按钮仍使用 `/api/linked-systems` 自动补齐数字孪生、能碳驾驶舱或马六甲推演；它们不会把“启动模拟器”重新解释成数字孪生。

所有启动入口只负责登记的本机演示系统。生产系统写入、真实设备控制和真实船舶指令继续保持关闭。
开源默认不绑定任何本机目录；未显式设置对应环境变量时，启动请求失败关闭。

## 本机端口契约

| 端口 | 唯一所有者 | 身份校验 |
| --- | --- | --- |
| 8010 | 小懿AI | 首页包含“港航小懿AI” |
| 8000 | 港口数字孪生 | 首页产品标识 + `/health/live` JSON |
| 8808 | 能碳驾驶舱后端 | `/api/health` 服务名 |
| 5173 | 能碳驾驶舱前端 | 产品 HTML 页面 |
| 5174 | 马六甲沙盘推演 | `/api/rl/health` 协议与服务名 |
| 11435 | 本地生成模型 | llama.cpp `/health` |
| 11436 | 本地向量模型 | llama.cpp `/health` |

契约源文件为 `config/local_ports.env`。启动器只有在端口响应与登记服务身份同时匹配时才会复用；端口被其他程序占用时会失败关闭并显示占用信息，不会把陌生服务误报为在线，也不会重复拉起同一后端。
