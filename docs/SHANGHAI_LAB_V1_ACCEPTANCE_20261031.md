# 上海港统一联动试验 V1 · 2026-10-31

本轮在保留原系统演示、既有训练数据、冠军策略和业务价值报告的条件下，完成七项逐项验收。范围为小懿 AI、能碳驾驶舱、港航韧性沙盘、PortAI 客户端及其共享 Port 后端。航行模拟器不修改、不训练、不启动。

准确成果口径：**四套系统已基于上海港真实公开资料完成统一输入的工程联动试验，包含独立复核、回执读回、状态恢复与实际 Flutter Web 签收。尚未完成上港集团现场联合验证。**

## 业务结果如何解释

73 组储能实验包括 48 个跨月日期、16 组压力情景和 9 组电价/折耗敏感性试算。固定假设下，费用套利改善伴随购电量与碳排上升。代表性日期费用减少约 3,494.37 元，碳排增加约 508.03 kgCO₂e，购电增加约 923.68 kWh。以上均为同一排程的工程日试算，不能年化为真实收益。

不同月份绝对套利收益几乎相同，是固定电价与未形成有效瓶颈共同导致的结果，不能把退化的统计区间宣传成高精度现场收益估计。因果控制器只读取当前负荷/PV，加上已知服务计划、电价与声明的预测形状；全时域事后强参考单列为不可直接部署的诊断下界。

第一版调度费用优先时出现等待增加，失败/不足证据保存在 `04-planning-attempt2`。增加总等待和逾期不劣门槛后的 29 例均通过，结果在 `04-planning-service-guard`。其中 2025-07-15 天气情景减少 2 船时等待，但总费用增加 88 元；该权衡保留，未筛掉不利结果。MILP 目标中优先级等待权重和逾期单价都是声明的工程偏好。

## 使用

在小懿根目录双击 `启动上海港统一试验.command`，或执行：

```bash
.venv/bin/python scripts/start_shanghai_lab_v1.py
# 状态检查
.venv/bin/python scripts/start_shanghai_lab_v1.py --status
# 若需要重新编译客户端
.venv/bin/python scripts/start_shanghai_lab_v1.py --build-mobile
```

访问 `http://127.0.0.1:18018/web/shanghai-lab.html`。原数据齐备检查 → 依据与换源里也有新增入口。选择日期和情景 → 运行并核验 → 检查费用/等待/碳排权衡 → 在 PortAI 复核签收 → 返回读取签收 → 下载证据包。通信中断案例会保留失败，不产生成功签收。

端口：小懿 18018，沙盘 18473，能碳后端 18808，能碳界面 18474，Port 后端 18800，PortAI 7357。启动器不占用旧后端演示端口；PortAI 7357 为本机 Web 客户端口。现有响应服务复用，未响应的占用端口报错，不杀其他进程。Ctrl-C 只停止本次启动器创建的子进程。

仓库迁移时可设置 `SHANGHAI_ENERGY_ROOT`、`SHANGHAI_MALACCA_ROOT`、`SHANGHAI_PORT_ROOT`、`SHANGHAI_MOBILE_ROOT`、`SHANGHAI_NODE`。Python 公共数据函数支持 `SHANGHAI_LAB_DATA_DIR`；下游服务从统一报文取数据，正常路径无需自行加载中央数据包。复验需 Python 3.12、SciPy（小懿 MILP）、Node 24 及现有各仓库依赖。未安装或升级原有学习框架。

## 实时替换与仍需完成的工作

`/api/harness/shanghai/catalog` 给出字段合同与实时替换位置：TOS 任务/ETA/设备生产率，AIS/VTS 到离港事件，EMS/BMS 功率与 SOC，计量与电价合同，气象观察/预报。统一记录须携带来源系统、源记录号、资产 ID、事件时间、接收时间、修订号、值、单位、质量和证据类别。

当前联动接口可以复用，但现场标识映射、时钟同步、迟到/修订处理、计量对账、参数校准、预报可得时间、身份授权、故障接管和影子运行验收仍须用实际港区接口完成。**不能将“只修改接口地址”说成生产上线已完成。** 本轮没有连接现场系统，也没有生产控制授权。

旧 RL 冠军保持原准入状态；本轮不宣称新 RL 优于旧策略。小懿自由问答泛化和原生推送未在本轮解决。新增证据读取工具为显式选用，默认工具目录和旧提示流程保持原样。

机器证据目录：`.codex_artifacts/shanghai-lab-v1-20261031/`。每次请求在 `.runtime/shanghai-lab-v1/` 留存不可混用的版本结果，签收使用独立 SQLite 事件链。最终实现源哈希随新试验记录及验收包封存；旧试验记录不会为补版本信息而改写。
